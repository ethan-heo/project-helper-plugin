# 학습 기조

## 목적과 문제

사용자가 정한 학습 원칙을 과제·힌트·피드백에 반영합니다. 원칙이 반영되지 않으면 AI가 사용자의 노력을 덜어 주는 방향으로 돕고, 학습한 내용이 기억에 남지 않습니다.

## 요구사항과 품질 속성

| 요구사항 | 판정 기준 |
| --- | --- |
| 원칙과 결과의 일치(R7) | 과제·힌트·피드백 중 기조 원칙과 어긋나는 것이 없다 |
| 원칙 변경의 반영(R8) | 원칙을 추가하고 관련 스킬 문서를 고친 뒤 만든 결과가 새 원칙과 어긋나지 않는다 |

## 개념 모델

| 개념 | 뜻 |
| --- | --- |
| 학습 기조 | 사용자가 정한 학습 원칙의 목록 |
| 적용 규칙 | 원칙 하나를 특정 스킬의 결과에 반영하는 방법 |

## 책임과 경계

| 구성 요소 | 맡는 일 |
| --- | --- |
| 기조 문서 | 원칙과 그 식별자의 보관 |
| 각 스킬 문서 | 자기 결과에 해당하는 원칙의 적용 규칙 보관 |
| 사용자 | 이 저장소에서의 원칙·적용 규칙 수정과 커밋 |

기조 문서에는 스킬별 적용 방법을 적지 않습니다(AD-002).

## 실행 흐름

1. 사용자가 기조 문서에 원칙을 추가하거나 고칩니다.
2. 그 원칙이 영향을 주는 스킬 문서의 적용 규칙을 함께 고칩니다.
3. 커밋하고 플러그인을 갱신합니다.
4. 새 세션에서 스킬이 바뀐 적용 규칙으로 결과를 만듭니다.

## 계약

| 정보 | 보내는 쪽 | 받는 쪽 |
| --- | --- | --- |
| 원칙과 그 식별자 | 기조 문서 | 각 스킬 문서의 적용 규칙 |

적용 규칙은 근거가 된 원칙을 식별자로 가리킵니다. 어느 적용 규칙도 가리키지 않는 원칙을 찾아내기 위해서입니다.

## 위험과 미해결 질문

| 위험·질문 | 내용 |
| --- | --- |
| 적용 규칙 누락 | 원칙을 추가하고 스킬 문서를 고치지 않으면 R8 미충족 |
