## 시스템의 목적

기술을 혼자 공부하는 개발자가 설명을 듣는 대신 과제를 직접 구현하며 배우게 하는 플러그인입니다. Claude Code와 Codex에서 함께 씁니다. 플러그인은 과제·학습 환경·힌트·피드백만 제공하고, 떠올리기와 복습 같은 학습 행동은 사용자가 직접 합니다.

요구사항은 [PRD](../prds/2026-09-19-학습-플러그인.md)의 R1~R8을 따릅니다.

## 공통 개념 모델

| 개념 | 뜻 |
| --- | --- |
| 과제 | 만들 대상과 완성 조건을 적은 구현 과제 하나 |
| 과제 폴더 | 과제 하나의 코드·의존성·과제 정보를 담는 폴더 |
| 과제 정보 | 과제 폴더에 기록한 기술·만들 대상·완성 조건 |
| 학습 기조 | 사용자가 정한 학습 원칙의 목록 |
| 사용자 스킬 | 사용자가 부르는 `study`·`hint`·`review` |
