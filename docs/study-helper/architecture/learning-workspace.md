# 학습 작업 공간

## 목적과 문제

사용자가 과제 코드를 작성하고 실행할 폴더를 만듭니다. 환경이 준비되지 않으면 사용자가 설치 문제에 시간을 쓰고, 과제에 들일 노력이 줄어듭니다.

## 요구사항과 품질 속성

| 요구사항 | 판정 기준 |
| --- | --- |
| 추가 설치 없는 실행(R1) | 과제 폴더를 만든 직후 과제 코드를 작성하고 실행한다 |
| 과제 사이의 독립 | 한 과제 폴더의 의존성을 바꿔도 다른 과제가 그대로 실행된다 |

## 개념 모델

| 개념 | 뜻 |
| --- | --- |
| 과제 폴더 | 과제 하나의 코드·의존성·과제 정보를 담는 폴더 |

## 책임과 경계

| 구성 요소 | 맡는 일 |
| --- | --- |
| `study` | 과제 폴더 생성, 과제 정보 기록, 의존성 설치 |
| 사용자 | 과제 폴더 안에서의 구현과 실행 |

과제 폴더에는 정답 코드를 넣지 않습니다. 과제 폴더를 언제 만들고 누가 읽는지는 [학습 진행](learning-flow.md)이 정합니다.

## 실행 흐름

1. `study`가 현재 디렉터리 바로 아래에 새 과제 폴더를 만듭니다.
2. 그 폴더에 과제 정보를 기록하고, 과제에 필요한 의존성을 설치합니다.
3. 사용자가 그 폴더에서 구현하고 실행합니다.

## 계약

과제 정보는 과제 폴더 안에 두고, 스킬 사이의 전달은 [학습 진행](learning-flow.md)의 계약을 따릅니다(AD-004).

## 위험과 미해결 질문

| 위험·질문 | 내용 |
| --- | --- |
| 반복 설치 | 같은 기술의 과제마다 같은 의존성을 다시 설치하는 시간과 용량 |
| 설치 실패 | 사용자 환경에 런타임이 없어 R1을 충족하지 못하는 경우의 처리 미정 |
