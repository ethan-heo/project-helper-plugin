# 학습 상태 처리 성능 비교

## 측정 범위

학습 시작과 학습자 답변 후 첫 설명까지의 시간을 우선 비교합니다. 약 30초와 추론 토큰 약 1,000개는 사용자가 제시한 참고값이며 측정된 평균이 아닙니다.

로컬 스크립트 실행 시간·명령 수·출력 바이트와 실제 AI 응답 시간·도구 호출·토큰을 구분합니다. 바이트를 토큰으로 환산하거나 스크립트 실행 시간을 전체 응답 시간으로 보고하지 않습니다.

## 고정 입력

| 상황 | 입력 |
| --- | --- |
| 시작 | `/learn` 후 JavaScript의 counter 선택 |
| 재개 | 진행 중인 두 번째 출력 질문 재개 |
| 일반 답변 | 증가 연산이 먼저 실행되는 것 같습니다 |
| 완료 | 반환 값이 증가한 값이기 때문입니다 |
| 정리 | `/tech-learning-helper:review` |

`skills/_shared/scripts/tests/fixtures/javascript/`의 데이터와 예제를 임시 Git 저장소에 복사합니다. 매회 같은 상태에서 시작하며 기존 질문 기록을 보존합니다. 새 예제 생성과 첫 설치 시간은 별도로 기록합니다.

## 로컬 비교

저장소 루트에서 다음 명령을 실행합니다. Python 3는 측정 도구에만 필요하며 학습 저장 명령의 실행 환경은 Bash·jq입니다.

```bash
python3 plugins/tech-learning-helper/skills/_shared/scripts/tests/measure.py before /tmp/learning-before.json
python3 plugins/tech-learning-helper/skills/_shared/scripts/tests/measure.py after /tmp/learning-after.json
```

각 상황을 5회 실행해 중앙값·최솟값·최댓값을 기록합니다. 비교 원본은 로컬 계획 디렉터리에 보관합니다. 시작·재개·정리의 기존 조회 절차와 새 명령을 비교하며, 일반 답변·완료의 기존 AI 작성 저장 명령은 고정된 동등 실행이 없으므로 로컬 시간 비교에서 제외합니다.

## 실제 학습 세션 비교

사용자가 지정한 비교 환경은 Claude Opus 5, 추론 low입니다. 실제 모델 식별자는 실행 환경에서 확인합니다. 변경 전후에 같은 앱·모델·추론 설정·데이터·입력을 사용합니다. 학습 시작은 목록 표시와 패키지 선택 후 첫 설명을 나눕니다. 단순 진행 안내는 첫 설명으로 세지 않습니다.

입력 제출부터 첫 설명, 설명 완료, 저장 완료까지의 시간을 각각 기록합니다. 도구 호출 수와 앱이 제공하는 입력·출력·추론 토큰도 기록합니다. 제공되지 않는 지표는 `null`과 사유를 남깁니다. 측정용 안내가 다음 학습 질문으로 해석되지 않도록 학습 입력과 측정을 구분합니다.

절감률은 `(변경 전 - 변경 후) / 변경 전 × 100`으로 계산합니다. 실측 전후 비교와 사용자 참고값 대비 비교는 별도 표에 둡니다. 응답 시간이 줄지 않으면 속도 개선으로 판정하지 않습니다.

## 진행 상태

변경 전 로컬 조회를 각 5회 측정하고, 시작·재개·일반 답변·완료·정리의 25개 표본 슬롯에 실측값과 미측정 사유를 남겼습니다. 실제 AI 응답 시간과 추론 토큰은 별도 학습 세션에서 관측해야 합니다. 실제 응답 시간 측정 전에는 전체 성능 비교를 완료로 표시하지 않습니다.
