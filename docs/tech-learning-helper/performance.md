# 학습 상태 처리 성능 비교

## 측정 범위

학습 시작과 학습자 답변 후 첫 설명까지의 시간을 우선 비교합니다. 약 30초와 추론 토큰 약 1,000개는 사용자가 제시한 참고값이며 측정된 평균이 아닙니다.

로컬 스크립트 실행 시간·명령 수·출력 바이트와 실제 AI 응답 시간·도구 호출·토큰을 구분합니다. 바이트를 토큰으로 환산하거나 스크립트 실행 시간을 전체 응답 시간으로 보고하지 않습니다.

## 고정 입력

| 상황 | 입력 |
| --- | --- |
| 시작 | `/learn` 후 JavaScript의 counter 선택 |
| 재개 | 진행 중인 두 번째 출력 질문 재개 |
| 일반 답변 | 증가 연산이 먼저 실행되는 것 같습니다 |
| 완료 | 반환 값이 증가한 값이기 때문입니다 |
| 정리 | `/tech-learning-helper:review` |

`skills/_shared/scripts/tests/fixtures/javascript/`의 데이터와 예제를 임시 Git 저장소에 복사합니다. 매회 같은 상태에서 시작하며 기존 질문 기록을 보존합니다. 새 예제 생성과 첫 설치 시간은 별도로 기록합니다.

## 로컬 비교

저장소 루트에서 다음 명령을 실행합니다. Python 3는 측정 도구에만 필요하며 학습 저장 명령의 실행 환경은 Bash·jq입니다.

```bash
python3 plugins/tech-learning-helper/skills/_shared/scripts/tests/measure.py before /tmp/learning-before.json
python3 plugins/tech-learning-helper/skills/_shared/scripts/tests/measure.py after /tmp/learning-after.json
```

각 상황을 5회 실행해 중앙값·최솟값·최댓값을 기록합니다. 비교 원본은 로컬 계획 디렉터리에 보관합니다. 시작·재개·정리의 기존 조회 절차와 새 명령을 비교하며, 일반 답변·완료의 기존 AI 작성 저장 명령은 고정된 동등 실행이 없으므로 로컬 시간 비교에서 제외합니다.

## 실제 학습 세션 비교

사용자가 지정한 비교 환경은 Claude Opus 5, 추론 low입니다. 실제 모델 식별자는 실행 환경에서 확인합니다. 변경 전후에 같은 앱·모델·추론 설정·데이터·입력을 사용합니다. 학습 시작은 목록 표시와 패키지 선택 후 첫 설명을 나눕니다. 단순 진행 안내는 첫 설명으로 세지 않습니다.

입력 제출부터 첫 설명, 설명 완료, 저장 완료까지의 시간을 각각 기록합니다. 도구 호출 수와 앱이 제공하는 입력·출력·추론 토큰도 기록합니다. 제공되지 않는 지표는 `null`과 사유를 남깁니다. 측정용 안내가 다음 학습 질문으로 해석되지 않도록 학습 입력과 측정을 구분합니다.

절감률은 `(변경 전 - 변경 후) / 변경 전 × 100`으로 계산합니다. 실측 전후 비교와 사용자 참고값 대비 비교는 별도 표에 둡니다. 응답 시간이 줄지 않으면 속도 개선으로 판정하지 않습니다.

## 변경 전후 로컬 결과

2026-09-15에 같은 macOS·Bash 3.2·jq 1.7.1 환경과 고정 데이터로 각 5회 측정했습니다. 변경 전 코드는 `3c0213b`, 변경 후 코드는 `9710953`입니다. 시간은 밀리초이며 괄호는 최솟값~최댓값입니다.

| 상황 | 변경 전 시간 중앙값 (범위) | 변경 후 시간 중앙값 (범위) | 실행 명령 수 | 출력 바이트 |
| --- | --- | --- | --- | --- |
| 목록 조회 | 90.2 (89.6~94.2) | 87.8 (82.9~101.4) | 2 → 2 | 434 → 434 |
| 재개 | 18.1 (17.6~20.6) | 115.2 (109.9~173.3) | 4 → 1 | 1,016 → 1,174 |
| 정리 | 42.4 (37.6~44.2) | 115.2 (112.5~191.7) | 6 → 1 | 1,675 → 1,691 |

재개와 정리의 실행 명령 수는 각각 75%, 83.3% 줄었습니다. 다만 새 명령에는 잠금·참조 검증·재개 후보 정규화가 포함되어 로컬 실행 시간은 각각 약 97ms, 73ms 늘었습니다. 출력도 각각 15.6%, 1.0% 늘었습니다. 이 결과만으로 응답 속도나 토큰 절감을 확인할 수는 없습니다. 명령 수는 측정 스크립트가 실행한 프로세스 수이며, AI가 실제로 호출한 도구 수와 다릅니다.

일반 답변과 완료는 통합 테스트에서 각각 한 저장 명령으로 처리되는 것을 확인했습니다. 기존 AI의 수작업 저장과 동등한 고정 실행이 없어 전후 시간 비교에서는 제외했습니다. 기록 보존·실패 복구·재시도·구형 상태 호환을 포함한 테스트 26개가 통과했습니다.

## 사용자 참고값과 실제 측정

| 지표 | 사용자 참고값 | 실제 변경 전 | 실제 변경 후 | 절감률 |
| --- | --- | --- | --- | --- |
| 시작·답변 후 응답 시간 | 약 30초 | 미측정 | 미측정 | 산출 불가 |
| 추론 토큰 | 약 1,000개 | 미측정 | 미측정 | 산출 불가 |

실제 세션을 측정하면 참고값 대비 절감률은 각각 `(30 - 변경 후 초) / 30 × 100`, `(1000 - 변경 후 추론 토큰) / 1000 × 100`으로 별도 계산합니다. 관측되지 않은 추론 토큰을 입력 토큰이나 출력 바이트로 대신하지 않습니다.

추가 최적화는 실제 세션에서 도구를 기다리는 시간, 지침 입력량, 설명 생성 시간을 먼저 구분한 뒤 결정합니다. 이번 변경은 현재 대화의 상태를 재사용하고 맥락이 부족할 때만 기록을 추가로 읽도록 했습니다. 스크립트 자체의 수십 ms보다 불필요한 도구 호출과 반복 지침 읽기가 실제 지연의 원인인지 확인하는 것이 다음 측정의 목적입니다.

## 진행 상태

스크립트 구현·스킬 적용과 로컬 전후 비교를 마쳤습니다. 측정 원본은 로컬 계획 디렉터리의 `before.json`·`after.json`에 있으며, 각각 25개 표본 슬롯에 측정값과 미측정 사유를 남겼습니다.

실제 Claude 세션의 응답 시간·토큰 관측 자료는 확보하지 못했습니다. 지정한 환경에서 변경 전후 각각 다섯 상황을 5회 측정해야 합니다. `LEARN-GUIDE-002`는 미완료로 유지하며, 실제 성능 개선 여부는 아직 판정하지 않습니다.
