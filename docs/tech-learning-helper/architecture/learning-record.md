# 학습 기록

## 목적과 문제

학습 상태가 남지 않으면 이미 공개한 설명을 되풀이하고, 질의응답이 남지 않으면 학습자가 배운 내용을 다시 정리할 근거가 없습니다. Claude Code의 새 세션은 이전 대화를 기억하지 못하므로, 이 영역은 학습 상태와 질의응답을 파일로 남깁니다.

## 요구사항과 품질 속성

| 요구사항 | 판정 기준 |
| --- | --- |
| 세션 안 상태 | 세션 도중 발견한 개념과 다음 탐색 후보를 확인할 수 있습니다 |
| 세션 간 복원 | 새 세션은 이어 하기 목록에서 패키지를 고른 뒤, 그 패키지의 상태 파일에서 직전 학습 상태를 이어 받습니다 |
| 전환 안전성 | 학습자가 설명 경로를 끝내지 않고 다른 저장소로 옮겨가도, 남겨 둔 저장소에 정리가 필요한 값이 남지 않습니다 |
| 패키지 구분 | 패키지가 여러 개인 저장소에서도 패키지별 진행 상태를 구분해서 확인합니다 |
| 질의응답 기록 | 질문별 기록 파일만 읽어도 해당 설명 경로를 따라갈 수 있습니다 |
| 주제와 날짜로 찾기 | 학습 패키지와 날짜 디렉터리만으로 기록을 찾습니다 |
| 학습 과정 이력 | 설명 경로 하나가 끝날 때마다 커밋이 하나 남습니다 |

## 개념 모델

| 개념 | 뜻 |
| --- | --- |
| 패키지 상태 파일 | 학습 패키지 하나 안의 세션 재개 상태(현재 질문·공개 단계·다음 기대 입력)와 누적 학습 상태(발견한 개념·부분 이해 개념·다음 탐색 후보)를 함께 담는 파일 |
| 질문 파일 | 학습 패키지 하나의 질문별 원문·관점·설명 경로·질문 상태를 담는 파일 |
| 저장소 상태 파일 | 기술 저장소 루트에 두는 인덱스 파일. 패키지마다 이름과 마지막 활동 날짜, 그리고 발견한 개념 이름 목록(패키지 무관하게 모음)만 담습니다. 진행 중인 패키지를 가리키는 값은 두지 않습니다 |
| 기록 파일 | 질문 하나의 설명 경로와 실험을 담은 Markdown 파일 |
| 질문 상태 | 기록 파일 하나가 가리키는 설명 경로의 진행 또는 완료 여부 |
| 발견한 개념 | 학습 중에 공개된 개념의 이름 |
| 부분 이해 개념 | 공개했지만 아직 전체 설명에 이르지 않은 개념 |
| 다음 탐색 후보 | 직전 질문과 이어져 다음에 다룰 수 있는 개념 |

## 책임과 경계

이 영역은 패키지 상태 파일, 저장소 상태 파일, 기록 파일을 쓰고 읽는 일과 설명 경로가 끝날 때의 커밋을 맡습니다(AD-017). 저장소 상태 파일은 인덱스일 뿐이므로 재개 지점을 판단하지 않으며, 재개 지점 판단은 학습자가 이어 하기 목록에서 패키지를 고른 뒤 그 패키지 상태 파일만으로 합니다. `review` 요청을 받으면 새 파일을 만들지 않고, 진행 중이거나 고른 패키지의 상태 파일 값을 그대로 학습 진행 영역에 넘깁니다(AD-015). 상태를 바꿀지는 학습 진행 영역이 판단하고, 이 영역은 받은 내용을 남깁니다. 이 영역의 규칙은 공용 참조 문서로 두고, `learn`과 `review`가 해당 단계에서 읽습니다(AD-007).

기술 저장소와 학습 패키지를 만드는 일은 학습 작업 공간 영역이 맡습니다. 두 영역은 같은 기술 저장소를 쓰지만, 이 영역은 예제 파일을 고치지 않습니다.

## 실행 흐름

1. 기술 이름 없이 이어 하기를 요청받으면, 학습 폴더의 기술 저장소를 최근 커밋 순으로 정렬해 학습 진행 영역에 목록으로 넘깁니다. 기술 이름만 받았는데 그 저장소가 있으면, 저장소 상태 파일의 패키지별 이름과 마지막 활동 날짜를 학습 패키지 목록으로 넘깁니다.
2. 학습자가 목록에서 패키지를 고르면, 그 패키지의 상태 파일에서 세션 재개 상태와 누적 학습 상태를 학습 진행 영역에 넘깁니다. 발견한 개념 이름 목록은 저장소 상태 파일에서 넘깁니다. 저장소 상태 파일은 어느 패키지를 재개할지 판단하지 않습니다.
3. 질의응답이 오갈 때마다 그 패키지의 상태 파일과 해당 질문의 기록 파일을 갱신합니다.
4. 설명 경로 하나가 끝나면 질문 파일의 질문 상태와 패키지 상태 파일의 발견한 개념·부분 이해 개념·다음 탐색 후보를 확정합니다. 저장소 상태 파일에서는 그 패키지의 마지막 활동 날짜를 갱신하고, 새로 발견한 개념의 이름을 더합니다. 기록 파일·질문 파일·패키지 상태 파일·저장소 상태 파일을 함께 커밋합니다.
5. `review`가 정리를 요청하면 진행 중이거나 고른 패키지의 상태 파일 값을 그대로 학습 진행 영역에 넘깁니다.

## 계약

| 정보 | 보내는 쪽 | 받는 쪽 |
| --- | --- | --- |
| 학습 상태와 질의응답 | 학습 진행 | 학습 기록 |
| 이전 학습 상태 | 학습 기록 | 학습 진행 |
| 발견한 개념 이름 목록 | 학습 기록 | 학습 진행 |
| 최근 순 기술 저장소 목록 | 학습 기록 | 학습 진행 |
| 패키지별 이름과 마지막 활동 날짜 | 학습 기록 | 학습 진행 |
| 설명 경로 종료 신호 | 학습 진행 | 학습 기록 |

파일 형식과 커밋 메시지 규칙은 계획서에서 정합니다. 따르는 결정은 AD-007, AD-014, AD-015, AD-017입니다.

## 위험과 미해결 질문

- 구형 저장소를 읽기 위한 호환 처리(날짜 단일 기록 파일, 문자열 후보, 구형 질문 파일)를 언제 제거할지는 정하지 않았습니다.
