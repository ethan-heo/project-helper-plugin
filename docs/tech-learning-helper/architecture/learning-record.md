# 학습 기록

## 목적과 문제

학습 상태가 남지 않으면 이미 공개한 설명을 되풀이하고, 질의응답이 남지 않으면 학습자가 배운 내용을 다시 정리할 근거가 없습니다. Claude Code의 새 세션은 이전 대화를 기억하지 못하므로, 이 영역은 학습 상태와 질의응답을 파일로 남깁니다.

## 요구사항과 품질 속성

| 요구사항 | 판정 기준 |
| --- | --- |
| 세션 안 상태 | 세션 도중 발견한 개념과 다음 탐색 후보를 확인할 수 있습니다 |
| 세션 간 복원 | 새 세션에서 저장소 상태 파일로 진행 중인 패키지를 확인한 뒤, 그 패키지의 상태 파일에서 직전 학습 상태를 이어 받습니다 |
| 패키지 구분 | 패키지가 여러 개인 저장소에서도 패키지별 진행 상태를 구분해서 확인합니다 |
| 질의응답 기록 | 질문별 기록 파일만 읽어도 해당 설명 경로를 따라갈 수 있습니다 |
| 주제와 날짜로 찾기 | 학습 패키지와 날짜 디렉터리만으로 기록을 찾습니다 |
| 학습 과정 이력 | 설명 경로 하나가 끝날 때마다 커밋이 하나 남습니다 |

## 개념 모델

| 개념 | 뜻 |
| --- | --- |
| 패키지 상태 파일 | 학습 패키지 하나 안의 세션 재개 상태(현재 질문·공개 단계·다음 기대 입력)와 누적 학습 상태(질문 상태·발견한 개념·부분 이해 개념·다음 탐색 후보)를 함께 담는 파일 |
| 저장소 상태 파일 | 기술 저장소 루트에 두고, 진행 중인 패키지·마지막 학습 패키지·발견한 개념 이름 목록(패키지 무관하게 모음)만 담는 파일 |
| 기록 파일 | 질문 하나의 설명 경로와 실험을 담은 Markdown 파일 |
| 질문 상태 | 기록 파일 하나가 가리키는 설명 경로의 진행 또는 완료 여부 |
| 발견한 개념 | 학습 중에 공개된 개념의 이름 |
| 부분 이해 개념 | 공개했지만 아직 전체 설명에 이르지 않은 개념 |
| 다음 탐색 후보 | 직전 질문과 이어져 다음에 다룰 수 있는 개념 |

## 책임과 경계

이 영역은 패키지 상태 파일, 저장소 상태 파일, 기록 파일을 쓰고 읽는 일과 설명 경로가 끝날 때의 커밋을 맡습니다(AD-016). `review` 요청을 받으면 새 파일을 만들지 않고, 진행 중이거나 고른 패키지의 상태 파일 값을 그대로 학습 진행 영역에 넘깁니다(AD-015). 상태를 바꿀지는 학습 진행 영역이 판단하고, 이 영역은 받은 내용을 남깁니다. 이 영역의 규칙은 공용 참조 문서로 두고, `learn`과 `review`가 해당 단계에서 읽습니다(AD-007).

기술 저장소와 학습 패키지를 만드는 일은 학습 작업 공간 영역이 맡습니다. 두 영역은 같은 기술 저장소를 쓰지만, 이 영역은 예제 파일을 고치지 않습니다.

## 실행 흐름

1. 기술 이름 없이 이어 하기를 요청받으면, 학습 폴더의 기술 저장소를 최근 커밋 순으로 정렬해 학습 진행 영역에 목록으로 넘깁니다. 기술 이름만 받았는데 그 저장소가 있으면, 저장소 상태 파일의 마지막 학습 패키지와 학습 패키지 목록을 넘깁니다.
2. 학습을 시작하면 저장소 상태 파일을 먼저 읽어 진행 중인 패키지를 확인하고, 그 패키지의 상태 파일에서 세션 재개 상태와 누적 학습 상태, 발견한 개념 이름 목록을 학습 진행 영역에 넘깁니다.
3. 질의응답이 오갈 때마다 그 패키지의 상태 파일과 해당 질문의 기록 파일을 갱신합니다.
4. 설명 경로 하나가 끝나면 패키지 상태 파일의 질문 상태·발견한 개념·부분 이해 개념·다음 탐색 후보를 확정하고, 새로 발견한 개념의 이름을 저장소 상태 파일에도 더합니다. 기록 파일·패키지 상태 파일·저장소 상태 파일·새로 저장된 지식을 함께 커밋합니다.
5. `review`가 정리를 요청하면 진행 중이거나 고른 패키지의 상태 파일 값을 그대로 학습 진행 영역에 넘깁니다.

## 위험과 미해결 질문

- 패키지 상태 파일과 저장소 상태 파일의 갱신 중 하나가 실패하면, 어느 패키지가 진행 중인지와 실제 기록이 어긋날 수 있습니다.
- 기존 날짜 단일 파일과 질문별 파일이 함께 있으면 정리할 때 두 형식을 모두 읽어야 합니다.
- 기존 `state.md`·저장소 루트의 `state.json`·`knowledge.md`·`summary.md`로 만들어진 저장소를 새 구조로 어떻게 옮길지는 정하지 않았습니다.
