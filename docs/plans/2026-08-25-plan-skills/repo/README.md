# REPO — 저장소와 플러그인 구조

## 요약

**목표** — 스킬을 담을 그릇을 만든다. 플러그인 매니페스트, 저장소 규약, 디렉터리 배치가 여기 속한다.

**배경** — 계획서의 구현 항목마다 커밋한다는 규칙을 지키려면 저장소와 커밋 규약이 스킬보다 먼저 있어야 한다. 대상 폴더는 비어 있는 상태에서 시작했다.

**변경점** — 빈 폴더에서 시작해 스킬을 얹을 수 있는 저장소로 만든다.

## 설계

이 도메인이 맡는 범위는 스킬 바깥이다. 저장소가 어떻게 생겼는가, 커밋 메시지를 어떻게 쓰는가, 플러그인이 어떤 파일로 자기를 설명하는가가 여기 있다. 스킬 본문에 무엇을 적는가는 `SKILL`, 계획서를 어떻게 쓰는가는 `FMT`다.

설계 근거와 실제 배치는 `REPO-SETUP`에 있다.

배포용 패키징은 여기가 아니라 `REL`이다. 저장소 구조를 정하는 것과 그 구조에서 배포물을 뽑아내는 것은 시점이 다르다.
