# 배포와_설치(distribution) — 도메인 개요

## 도메인 정의

플러그인을 Claude Code와 Codex 두 환경에 배포하고 설치하는 영역이다. 마켓플레이스 매니페스트와 두 플러그인 매니페스트가 갖춰야 할 조건, 개발 중의 로컬 재설치 절차, 배포 대상과 개발용 파일의 구분을 담당한다.

스킬의 내용이 아니라 스킬을 담은 껍데기를 다룬다. 어떤 파일이 설치본에 복사되는지가 이 도메인의 판정 기준이다.

### 책임 범위

| 구분 | 내용 |
| --- | --- |
| 담당한다 | 마켓플레이스 진입점, 두 환경의 플러그인 매니페스트, 버전 정합, 배포 대상 판정, 로컬 재설치 절차, 설치 결과 확인 |
| 담당하지 않는다 | 스킬 내부의 절차와 참조 문서, 발동 조건 서술(스킬_실행_맥락) |

## 유비쿼터스 용어 사전

| 용어 | 영문 표기 | 정의 |
| --- | --- | --- |
| 마켓플레이스 | marketplace | 플러그인 목록의 진입점. 이 저장소 루트가 마켓플레이스다 |
| 마켓플레이스 매니페스트 | `.claude-plugin/marketplace.json` | 플러그인 이름과 소스 경로를 담는 파일. 두 환경이 함께 읽는다 |
| 플러그인 매니페스트 | `plugin.json` | 버전과 설명을 담는 파일. 환경마다 다른 파일을 읽는다 |
| 설치본 | installed copy | 플러그인 캐시에 복사되는 파일 묶음 |
| 로컬 테스트 설치 | local install | 저장소의 현재 파일을 그대로 설치해 확인하는 개발용 절차 |
| 배포 대상 | distribution target | 설치본에 복사되는 파일. 복사되지 않으면 개발용이다 |

## 핵심 비즈니스 규칙

1. 두 환경 모두 저장소 루트의 `.claude-plugin/marketplace.json` 하나를 마켓플레이스 진입점으로 읽는다. Codex 전용 마켓플레이스 매니페스트는 필요하지 않다.
2. 플러그인 매니페스트는 환경마다 다르다. Claude Code는 `.claude-plugin/plugin.json`을, Codex는 `.codex-plugin/plugin.json`을 읽는다.
3. 두 플러그인 매니페스트의 버전은 항상 함께 올린다. 한쪽만 올리면 같은 소스가 환경마다 다른 버전으로 표시된다.
4. 배포 대상 여부는 설치본에 복사되는지로 판정한다. `plugins/project-helper/` 아래의 `.claude-plugin`, `.codex-plugin`, `skills`만 복사되며 `docs/`, `evals/`, `README.md`, 지시사항 파일은 개발용이다. 매니페스트에는 복사 대상을 제외하는 필드가 없으므로, 배포에서 빼야 할 파일은 플러그인 디렉터리 밖에 둔다.
5. 마켓플레이스 매니페스트의 `source`는 저장소 루트 기준 상대 경로다. 원격 저장소로 옮겨도 그대로 동작한다.
6. 스킬 파일을 고친 내용은 설치된 플러그인에 자동으로 반영되지 않는다. 재설치한 뒤 새 세션에서 확인한다.
7. 재설치를 위해 매니페스트의 버전에 타임스탬프를 덧붙이지 않는다. 캐시는 해당 플러그인의 캐시 디렉터리를 지우는 것으로 충분하다.
8. 플러그인을 삭제할 때는 해당 플러그인의 캐시 디렉터리만 지운다. 전체 캐시 디렉터리는 지우지 않는다.
9. 마켓플레이스 설정 파일은 직접 고치지 않고 플러그인 명령으로 다룬다.

### 예외 케이스

| 상황 | 처리 |
| --- | --- |
| Codex에서 소스 변경이 반영되지 않는다 | 개발 모드가 없으므로 캐시 디렉터리를 지우고 재설치한다 |
| 실행 중인 세션에 변경이 반영되지 않는다 | 세션을 다시 시작한다. VS Code 확장에서는 창을 새로 고친 뒤 세션을 다시 연다 |
| 저장소가 아닌 별도 사본을 마켓플레이스로 쓴다 | 저장소의 플러그인 디렉터리를 그 경로에 심링크로 연결할 수 있다. 심링크는 재설치 시점의 소스만 바꾸며 실행 중인 캐시를 갱신하지는 않는다 |
| 원격 Git 소스로 등록한다 | 두 환경 모두 `<owner>/<repo>` 형태를 받아 클론한다. 설치본은 저장소가 아니라 각 환경의 캐시에서 온다 |
| 비공개 저장소의 인증 처리 | 아직 확인하지 않았다. 공개 저장소로만 등록을 확인했다 |
