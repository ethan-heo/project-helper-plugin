# 개발문서_생성(create-docs) — 도메인 개요

## 도메인 정의

`create-docs` 스킬이 담당하는 영역이다. 구현이 끝난 뒤 PRD에서 의도를, 계획서에서 결정을, 코드에서 사실을 가져와 세 층 구조의 개발 문서로 정리한다. 사용자는 도메인 이름과 재생성 범위의 결정권자이고, 스킬은 조사·작성·보고를 맡는다.

이 문서 묶음 자체가 이 도메인의 산출물이다. 지금 읽고 있는 파일도 같은 절차로 만들어졌다.

### 책임 범위

| 구분 | 내용 |
| --- | --- |
| 담당한다 | 진입 조건 확인, 보관 경로와 도메인 디렉터리 결정, 도메인 문서 네 편의 작성, 상위 두 층의 작성, 형식 검증과 미확인 정리 |
| 담당하지 않는다 | 도메인 경계의 신설, 보관 경로의 탐색 규칙 정의(문서_루트_판정), 코드 수정, 계획서 수정, 요구사항이나 구현 방식의 결정 |

## 유비쿼터스 용어 사전

| 용어 | 영문 표기 | 정의 |
| --- | --- | --- |
| 세 층 구조 | three layers | 글로벌 아키텍처 가이드, 공통 인프라 및 컨벤션, 도메인 문서로 나뉜 배치 |
| 도메인 문서 | domain document | 도메인 하나에 대응하는 개요·모델·API·특화 가이드 네 편 |
| 미확인 | unresolved marker | 근거를 찾지 못한 자리에 남기는 주석. 하나라도 남으면 확정하지 않는다 |
| 해당 없음 | not applicable | 그 항목이 이 도메인에 해당하지 않을 때 절을 지우는 대신 적는 표기 |
| 전체 재생성 | full regeneration | 기존 문서를 절 단위로 고치지 않고 대상 전체를 다시 만드는 방식 |
| 어긋난 지점 | discrepancy | 코드와 계획서의 기술이 다른 자리. 본문에 섞지 않고 따로 모아 보고한다 |

## 핵심 비즈니스 규칙

1. 이 스킬은 구현이 끝난 뒤에 실행한다. 계획서의 단계가 `완료`가 아니면 문서를 만들지 않는다.
2. 코드를 사실로 삼는다. 세 입력이 어긋나면 코드를 본문에 쓰고, 어긋난 지점은 따로 모아 사용자에게 보고한다.
3. 근거를 찾지 못한 자리는 추측으로 채우지 않고 미확인 주석을 남긴다. 미확인이 하나라도 남아 있으면 확정하지 않는다.
4. 도메인 경계는 계획서의 구조를 그대로 따르고 새로 정하지 않는다.
5. 기존 문서가 있으면 전체를 다시 생성한다. 덮어쓰기 전에 대상 목록을 사용자에게 보이고 동의를 받는다.
6. 한 도메인 안에서는 개요 → 모델 → API → 특화 가이드 순서로 쓴다. 앞 문서에서 정한 용어를 뒤 문서가 그대로 사용한다.
7. 상위 두 층은 도메인 문서를 모두 채운 뒤에 쓴다. 도메인 목록과 도메인 간 통신은 도메인 문서가 확정된 뒤에야 정확해진다.
8. 여러 도메인에 반복되는 내용은 상위 층으로 올리고 도메인 문서에는 참조 경로만 남긴다.
9. PRD와 계획서를 출처로 기록하지 않는다. 경로나 항목 ID를 문서에 남기면, 그 문서가 정리될 때 개발 문서가 깨진 참조를 안는다.
10. 해당 사항이 없는 절도 지우지 않는다. "해당 없음"과 그 이유를 적는다.
11. 문서를 쓰는 과정에서 코드를 고치지 않는다. 고칠 곳을 발견하면 알리되 손대지 않는다.

### 예외 케이스

| 상황 | 처리 |
| --- | --- |
| 단계가 `계획 완료`인 계획서가 있다 | 문서를 만들지 않고 `/impl-plan`으로 구현을 먼저 마치도록 안내한다 |
| PRD를 찾지 못한다 | 코드와 계획서만으로 쓰되, 근거에 PRD가 없다는 점을 알린다 |
| 도메인 이름이 영문 코드뿐이다 | 한글 이름을 사용자에게 확인받아 `회원_도메인(User_Domain)` 형태로 짓는다 |
| 계획서의 도메인이 코드의 모듈 경계와 다르다 | 계획서를 따르고 차이를 보고한다 |
| 계획서에 없는 도메인이 코드에 있다 | 문서를 만들지 않고 발견 사실만 기록한다 |
| 보관 경로에 다른 문서 체계가 이미 있다 | 덮어쓰지 않고 사용자에게 경로를 확인받는다 |
| 어긋난 지점이 계획의 전제를 흔든다 | 문서는 확정하되 `/create-plan`으로 계획을 고칠 것을 안내한다 |
| 사용자가 미확인을 남긴 채 마무리하기를 요청한다 | 초안임을 문서에 표시한다 |
