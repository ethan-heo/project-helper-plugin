# 개발문서_생성(create-docs) — API 명세

## 엔드포인트 목록

| 메서드 | 경로 | 설명 | 인증 |
| --- | --- | --- | --- |
| `호출` | `/create-docs` | 완료된 계획서와 코드를 근거로 개발 문서를 생성한다 | 불필요 |
| `자동 발동` | 자연어 요청 | "개발 문서 만들어줘", "도메인 문서 갱신해줘" 같은 요청에서 켜진다 | 불필요 |
| `실행` | `scripts/validate-docs.sh <보관 경로>` | 필수 파일, 절 구성, 미확인 잔존을 검사한다 | 불필요 |

## `/create-docs`

구현이 끝난 뒤 호출한다. 계획서 후보가 여럿이면 사용자에게 고르게 하고, 단계가 `완료`가 아닌 계획서가 있으면 진행하지 않는다.

### 요청

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 명령 인자 | 대상 지시 | string | 아니오 | 문서화할 범위. 비어 있으면 후보를 보여 고르게 한다 |
| 대화 | 보관 경로 | string | 조건부 | 문서 루트 판정으로 정한다. 후보가 여럿이라 좁혀지지 않을 때만 확인받는다 |
| 대화 | 도메인 이름 | string | 조건부 | 계획서의 도메인 이름이 영문 코드뿐일 때 확인받는다 |
| 대화 | 덮어쓰기 동의 | boolean | 조건부 | 보관 경로에 기존 문서가 있을 때 받는다 |

```
/create-docs 문서화해주세요
```

### 응답

산출물은 세 층 구조의 마크다운 파일 묶음이다. 도메인이 여섯이면 파일은 스물일곱 편이 된다.

```
docs/
├── 글로벌_아키텍처_가이드.md
├── 공통_인프라_및_컨벤션/
│   ├── 공통_에러_코드.md
│   └── 인증_및_인가_가이드.md
└── 도메인_문서/
    └── 계획_작성(create-plan)/
        ├── 01_도메인_개요.md
        ├── 02_도메인_모델.md
        ├── 03_API_명세.md
        └── 04_도메인_특화_가이드.md
```

확정 시점에는 생성한 파일 목록과 함께, 코드와 계획서가 어긋난 지점의 목록을 보고한다.

### 에러 코드

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| 해당 없음 | 진입 거부 | 단계가 `계획 완료`인 계획서가 남아 있다. `/impl-plan`으로 안내한다 |
| 해당 없음 | 경로 확인 요청 | 보관 경로에 다른 문서 체계가 이미 있다 |
| 해당 없음 | 동의 없음 | 덮어쓰기 동의를 받지 못했다. 아무것도 쓰지 않는다 |
| 해당 없음 | 확정 거부 | 미확인 주석이 남아 있거나 검증 스크립트가 실패했다 |

## `scripts/validate-docs.sh <보관 경로>`

확정 직전에 실행한다. 필수 파일의 존재, 절 제목의 존재, 미확인 주석의 잔존을 검사하며, 도메인 디렉터리는 개수를 세지 않고 발견한 전부를 검사한다.

미확인 검사의 대상은 글로벌 아키텍처 가이드 한 편과 `공통_인프라_및_컨벤션/`, `도메인_문서/` 두 디렉터리다. 문서 루트 아래에 함께 놓이는 `plans/`와 `prds/`는 개발 문서가 아니므로 검사하지 않는다.

### 요청

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 인자 1 | 보관 경로 | path | 예 | 디렉터리가 없으면 즉시 종료한다 |

```bash
bash plugins/project-helper/skills/create-docs/scripts/validate-docs.sh docs
```

### 응답

```
개발 문서 검증 통과: docs
```

### 에러 코드

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| 1 | `<경로> 디렉터리가 없습니다.` | 인자가 가리키는 디렉터리가 없다 |
| 1 | `<경로> 파일이 없습니다.` | 필수 파일 일곱 종 가운데 하나가 없다 |
| 1 | `<경로>에 '<절 이름>' 절이 없습니다.` | 해당 절이 2단계나 3단계 헤더로 없다 |
| 1 | `도메인 디렉터리가 하나도 없습니다.` | `도메인_문서/` 아래가 비어 있다 |
| 1 | `<경로>에 미확인 표시가 남아 있습니다.` | 미확인 주석이 남아 있다 |

## 이벤트 메시징

해당 없음. 문서 생성은 이벤트를 발행하지 않는다. 산출된 문서는 다음 계획을 세울 때 `create-plan`의 준비 단계가 파일을 직접 읽는 방식으로만 소비된다.
