# 요구사항_정의(create-prd) — 도메인 특화 가이드

## 외부 의존성

| 대상 | 종류 | 용도 |
| --- | --- | --- |
| `grep` | 명령줄 도구 | `scripts/validate-prd.sh`가 절 제목과 요구사항 표기를 검사한다 |
| `sed` | 명령줄 도구 | `미해결 질문` 절 이후의 내용만 잘라 남은 행을 센다 |

이 도메인의 검증 스크립트는 다른 두 스크립트와 마찬가지로 POSIX 도구만 쓴다.

### 설정

| 항목 | 값의 출처 | 비고 |
| --- | --- | --- |
| PRD 보관 경로 | [문서_루트_판정](../문서_루트_판정%28docs-root%29/01_도메인_개요.md)의 탐색 순서 | `<루트>/prds/`를 쓴다. 디렉터리가 없으면 만든다. 작업 대상 코드가 없으므로 조상 기준은 쓰지 않는다 |
| `.gitignore` 등록 | 저장소 루트의 `.gitignore` | 이 저장소에는 `docs/project-helper/prds/`가 등록되어 있다 |
| 필수 절 목록 | `scripts/validate-prd.sh`의 `sections` 배열 | 양식의 절 제목을 바꾸면 스크립트도 함께 고친다 |

## 핵심 테스트 시나리오

| ID | 상황 | 기대 동작 |
| --- | --- | --- |
| T1 | 기능 하나의 구현 방식을 PRD로 쓰자고 요청한다 | 작성을 시작하지 않고 `/create-plan`을 안내한다 |
| T2 | 사용자 카테고리에서 "모든 사용자"라고 답한다 | 넘어가지 않고 직군이나 상황을 되묻는다 |
| T3 | 목표에 "응답이 빠르다"고 답한다 | 관찰 가능한 기준으로 바꾸도록 되묻는다 |
| T4 | 카테고리를 건너뛰자고 요청한다 | 절을 비우지 않고 미확정 내용을 `미해결 질문`으로 옮긴다 |
| T5 | 요구사항에 구분 표시가 없는 PRD를 검증한다 | 검증이 실패한다 |
| T6 | 미해결 질문이 남은 PRD를 확정하려 한다 | 확정하지 않는다. 사용자가 요청하면 초안임을 표시한다 |
| T7 | 답변이 구현 방식으로 흐른다 | PRD의 범위가 아님을 알리고 목적과 요구사항으로 되돌린다 |

### 실행 방법

```bash
bash -n plugins/project-helper/skills/create-prd/scripts/validate-prd.sh
bash plugins/project-helper/skills/create-prd/scripts/validate-prd.sh docs/prds/<파일>.md
```

T5만 스크립트로 판정할 수 있다. 나머지는 설치된 세션에서 대화로 확인한다.

## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 절이 있는데 "절이 없습니다"가 나온다 | 절 제목이 `## <이름>`과 완전히 일치하지 않는다. 뒤에 붙은 공백이나 수식어도 불일치로 판정된다 | 양식의 절 제목을 그대로 쓴다 |
| 요구사항 표가 있는데 검증이 실패한다 | ID가 `R1` 형식이 아니거나 구분이 `필수`·`선택`이 아니다 | 표기를 양식에 맞춘다 |
| 미해결 질문을 지웠는데 잔존으로 잡힌다 | 표의 머리글과 구분선 외의 빈 행이 남아 있다 | 남은 행을 지우거나 내용을 확정해 다른 절로 옮긴다 |
| 질문이 끝없이 이어진다 | 넘어갈 조건을 만족하지 못한 카테고리에서 답변이 반복된다 | 그 카테고리의 넘어갈 조건을 사용자에게 보여 무엇이 더 필요한지 좁힌다 |
| PRD가 계획서처럼 길어진다 | 해법과 구현 방식이 섞여 들어갔다 | 구현 관련 문장을 덜어 내고 `/create-plan`으로 옮긴다 |
| PRD가 Git 상태에 잡힌다 | 보관 경로가 `.gitignore`에 없다 | 보관 경로를 등록하거나 사용자에게 보관 방식을 확인한다 |
