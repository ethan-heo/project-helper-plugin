## 시스템의 목적

`project-helper`는 Claude Code와 Codex에서 함께 쓰는 플러그인입니다. 무엇을 만들지 정하는 일부터 구현과 커밋 학습까지를 여섯 스킬이 나눠 맡고, 스킬마다 사용자와의 질의응답이나 정해진 절차를 거쳐 문서 산출물을 남깁니다.

각 스킬은 앞선 스킬의 산출물을 입력으로 읽을 수 있지만, 지금 필요한 스킬 하나만 따로 호출해도 동작합니다. 산출물은 PRD, 아키텍처 문서, 계획서, 커밋 학습 문서 순서로 이어지며, 모두 대상 저장소의 문서 루트 아래에 모입니다.

실행 코드는 없습니다. 스킬은 마크다운 지시 문서와 양식, 셸 검증 스크립트로 이루어지고, 이 문서를 읽은 AI 에이전트가 대상 저장소에서 절차를 수행합니다.

## 공통 개념 모델

| 개념 | 뜻 |
| --- | --- |
| 스킬 | `SKILL.md`를 진입점으로 삼는 실행 절차 묶음 |
| 대상 저장소 | 스킬이 실행되어 산출물을 남기는 저장소 |
| 산출물 | 스킬이 대상 저장소에 남기는 문서 |
| 문서 루트 | 산출물 디렉터리를 모아 두는 기준 경로 |
| 정본 | 여러 스킬이 참조하는 규칙의 유일한 원본 |
| 구조 결정 | 둘 이상의 계획이나 구성 요소 간 계약에 걸친 결정 |
| 구현 항목 | 커밋 하나에 대응하는 계획서의 작업 단위 |
| 설치본 | 설치할 때 플러그인 캐시에 복사되는 파일 묶음 |
