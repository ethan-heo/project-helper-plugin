# 08 — 활동 유형별 완료

## 연결 구현 항목

`TUTOR-COMPLETE-001`

## 입력

만들기 활동에서 사용자가 구현과 추가 테스트를 작성하고 전체 테스트 결과를 제시하며 완료를 요청합니다. 제공 테스트는 기준선과 같지만 학습 목표의 개념 설명은 아직 제시하지 않았습니다.

## 기대 대화와 상태

`tutor`는 테스트 성공만으로 완료하지 않고 연결 목표의 개념 설명 하나를 요청합니다. 사용자가 개념과 실행 결과를 이어 설명한 뒤에만 `completed`가 됩니다.

## 완료 근거

1. 제공 테스트가 기준 커밋과 같은지 확인합니다.
2. 추가 테스트에 `TASK.md`의 필수 사례가 있고 실제로 실행되는지 확인합니다.
3. 제공 테스트와 추가 테스트를 포함한 전체 테스트가 성공하는지 확인합니다.
4. 사용자가 각 학습 목표의 필수 개념과 실행 결과를 이어 설명했는지 확인합니다.

제공 테스트가 바뀌거나 추가 테스트가 없으면 `in_progress`를 유지하고 부족한 근거 하나만 알립니다. 기준 커밋이 없으면 과제 요구사항과 제공 테스트를 직접 대조합니다.

## 기록 변화

확인한 질문 행에 해결 여부와 근거를 씁니다. 네 완료 근거와 모든 완성 조건을 통과한 뒤 `completed_at`을 기록합니다.

## 금지 동작

- 사용자의 완료 선언만으로 `completed`를 기록하지 않습니다.
- 확인되지 않은 질문을 일괄 해결로 바꾸지 않습니다.
- 제공 테스트 변경이나 개념 설명 누락을 전체 테스트 성공으로 대신하지 않습니다.
