# 02 — 복수 런타임 선택

## 연결 구현 항목

`INIT-FLOW-001`

## 입력

같은 활동을 Node.js와 Bun에서 실행할 수 있고 두 런타임이 모두 설치되어 있습니다.

## 기대 대화와 상태

`init`은 활동과 수준을 확정한 뒤 두 런타임의 차이를 보이고 하나를 선택받습니다. 선택 뒤 `preparing`으로 전환합니다.

## 기록 변화

사용자가 고른 런타임 이름과 버전을 `runtime`에 기록합니다.

## 금지 동작

- 런타임을 임의로 고르지 않습니다.
- 활동을 정하기 전에 환경부터 묻지 않습니다.
