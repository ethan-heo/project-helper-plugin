# 05 — 옛 기록 변환

## 연결 구현 항목

`COMMON-RECORD-001`

## 입력

스키마 버전과 `.study-id`가 없는 옛 기록을 세 스킬 중 하나가 처음 읽습니다. 기록에는 질문 이력이 있고 완료 날짜는 없습니다.

## 기대 대화와 상태

원본을 시각별 백업 디렉터리에 복사한 뒤 UUID를 발급합니다. 새 기록의 상태는 `in_progress`가 됩니다.

## 기록 변화

예제 폴더에 `.study-id`를 만들고 `.study/records/<UUID>.md`에 YAML 머리말과 본문 네 절을 씁니다.

## 금지 동작

- 백업 전에 원본을 바꾸거나 지우지 않습니다.
- 변환 실패 뒤 새 형식을 쓴 것처럼 실행하지 않습니다.
