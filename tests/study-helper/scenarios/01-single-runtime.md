# 01 — JavaScript 클로저 만들기

## 연결 구현 항목

`INIT-FLOW-001`

## 입력

사용자는 함수 실행이 끝난 뒤에도 상태가 유지되는 이유를 익히기 위해 JavaScript 클로저 만들기를 고릅니다. `createCounter(initialValue)`가 호출할 때마다 값을 1씩 늘려 반환하는 함수를 만드는 활동이며 최종 수준은 숙련입니다. 실행 가능한 환경은 현재 브라우저 하나뿐입니다.

## 기대 대화와 상태

`init`은 브라우저를 선택한 근거만 알리고 런타임을 묻지 않습니다. 미구현 뼈대와 핵심 테스트를 시작 자료로 추천하고, 사용자가 확정한 뒤에만 파일을 만듭니다.

## 생성 결과

- `TASK.md`는 `createCounter(initialValue)`의 입력·출력, 상태 유지 동작, `src/create-counter.js` 산출물 경로를 과제 요구사항으로 적습니다.
- 제공 테스트는 `tests/provided/create-counter.test.js`, 추가 테스트는 `tests/learner/create-counter.test.js`로 분리합니다.
- `src/create-counter.js`는 공개 함수 형태만 내보내고 호출하면 `STUDY_NOT_IMPLEMENTED` 오류를 냅니다.
- `PLAN.md`는 파일 책임과 호출 관계, 첫 구현 작업과 추가 테스트 작업을 적되 상태 저장 위치나 정답 코드는 밝히지 않습니다.

## 초기 검증

제공 테스트가 한 개 이상 발견되고 `STUDY_NOT_IMPLEMENTED`로 실패한 뒤에만 기준 커밋을 만들고 `ready`로 바꿉니다. 테스트가 0개이거나 처음부터 통과하면 `preparing`을 유지합니다.

## 기록 변화

`language`와 `runtime`에 확인한 단일 후보를 쓰고 추천 수준·최종 수준·근거를 함께 기록합니다. 초기 검증 결과와 기준 커밋도 기록합니다.

## 금지 동작

- 이미 하나로 정해진 런타임을 다시 묻지 않습니다.
- 사용자 확정 전에 예제 폴더를 만들지 않습니다.
- 숙련 수준이라는 이유로 뼈대와 제공 테스트를 빼지 않습니다.
- 함수 내부 상태 위치나 완성 코드를 제시하지 않습니다.
