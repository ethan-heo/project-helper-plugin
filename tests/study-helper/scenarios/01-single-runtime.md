# 01 — 단일 런타임

## 연결 구현 항목

`INIT-FLOW-001`

## 입력

사용자가 브라우저 Web API만으로 동작하는 예제를 고르고 수준을 확정합니다. 실행 가능한 환경은 현재 브라우저 하나뿐입니다.

## 기대 대화와 상태

`init`은 브라우저를 선택한 근거만 알리고 런타임을 묻지 않습니다. 기록 상태는 `preparing`이 됩니다.

## 기록 변화

`language`와 `runtime`에 확인한 단일 후보를 쓰고 추천 수준·최종 수준·근거를 함께 기록합니다.

## 금지 동작

- 이미 하나로 정해진 런타임을 다시 묻지 않습니다.
- 사용자 확정 전에 예제 폴더를 만들지 않습니다.
