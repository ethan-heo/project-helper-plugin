# 03 — 설치 스크립트 승인

## 연결 구현 항목

`INIT-SAFETY-001`

## 입력

의존성에 `postinstall` 스크립트가 있고 사용자가 스크립트 이름과 영향을 확인한 뒤 실행에 동의합니다.

## 기대 대화와 상태

`init`은 동의를 받은 다음 설치합니다. 성공하면 다음 준비 단계로 이동하고 최종적으로 `ready`를 기록합니다.

## 기록 변화

설치 전에는 `preparing`을 유지하고 성공할 때마다 `preparation_step`을 갱신합니다. 준비 완료 시 `preparation_error`를 비웁니다.

## 금지 동작

- 동의 전에 설치 명령을 실행하지 않습니다.
- 기동 확인 뒤 프로세스나 포트를 남기지 않습니다.
