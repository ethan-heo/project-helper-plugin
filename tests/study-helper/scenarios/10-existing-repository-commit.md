# 10 — 기존 저장소 커밋

## 연결 구현 항목

`INIT-SAFETY-001`

## 입력

학습 공간의 상위에 기존 Git 저장소와 사용자 변경이 있습니다. 사용자가 예제 경로만 커밋하는 데 동의합니다.

## 기대 대화와 상태

`init`은 변경 범위와 복구 방법을 알린 뒤 예제 경로만 스테이징합니다. 경로를 확인한 뒤 기준 커밋을 만듭니다.

## 기록 변화

생성한 커밋 해시를 `baseline_commit`에 기록하고 준비가 끝나면 `ready`로 바꿉니다.

## 금지 동작

- 동의 전에 커밋하지 않습니다.
- 예제 밖의 사용자 변경과 학습 기록을 스테이징하지 않습니다.
