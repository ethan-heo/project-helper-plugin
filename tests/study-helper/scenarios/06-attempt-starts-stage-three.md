# 06 — 시도 정보가 있는 질문

## 연결 구현 항목

`TUTOR-ANSWER-001`

## 입력

사용자가 시도한 명령과 관찰한 오류, 막힌 지점을 한 질문에 함께 적습니다.

## 기대 대화와 상태

첫 `tutor` 호출이면 `in_progress`로 전환하고 새 주제를 3단계에서 시작합니다. 관련 개념과 다음 확인 지점만 답합니다.

## 기록 변화

새 주제 행에 연결 목표, 최대 도움 단계 `3`, 해결 여부 `아니요`, 빈 확인 근거를 기록합니다.

## 금지 동작

- 이미 적은 시도와 막힌 지점을 다시 묻지 않습니다.
- 4단계 코드 설명이나 5단계 코드 조각을 먼저 주지 않습니다.
