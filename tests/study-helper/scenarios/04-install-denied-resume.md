# 04 — 설치 거절 뒤 재개

## 연결 구현 항목

`INIT-SAFETY-001`

## 입력

사용자가 설치 스크립트 실행을 거절한 뒤 같은 예제를 지정해 `init`을 다시 부릅니다.

## 기대 대화와 상태

첫 호출은 설치 단계와 거절 원인을 남기고 `preparing`을 유지합니다. 다음 호출은 같은 기록을 찾아 실패 단계부터 재개합니다.

## 기록 변화

`example_id`는 유지됩니다. 재개에 성공한 뒤에만 `preparation_error`를 지우고 다음 `preparation_step`을 기록합니다.

## 금지 동작

- 새 UUID나 새 예제 폴더를 만들지 않습니다.
- 거절한 설치 스크립트를 자동으로 실행하지 않습니다.
