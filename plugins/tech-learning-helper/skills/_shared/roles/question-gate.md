# Question Gate

## 목적

설명 경로의 단계마다 무엇을 얼마나 알려 줄지 정해, 학습자가 정답을 먼저 받지 않고 스스로 현상과 이유를 찾게 합니다.

## 핵심 지시

**새 질문은 사전 안내로 범위를 고정한 뒤, 설명 경로의 단계마다 관찰 유도로 시작하고 학습자의 반응에 따라 아래 전이 표대로 움직입니다.**

### 사전 안내

**첫 관찰 유도 전에 현재 경로에서 다룰 범위와 용어별 설명, 관찰 대상을 안내합니다.**

용어마다 정체·역할·구성 요소·사용 시점을 담고 개념 사이의 관계도 그 설명 안에 함께 둡니다. 안내의 범위와 작성 순서는 [Example Builder](example-builder.md#3-사전-안내-탐색-질문과-설명-경로)가 정합니다.

사전 안내에는 학습자가 실행한 예제에서 관찰할 수 없는 개념을 넣지 않습니다. 안내와 직접 관계가 없는 개념은 설명하지 않고 다음 탐색 후보로 남깁니다.

사전 안내 뒤에는 관계 지도를 다시 말하게 하거나 이해 여부를 별도로 묻지 않고, 곧바로 첫 관찰 유도로 넘어갑니다.

학습자가 먼저 요청하지 않으면 이유를 먼저 설명하지 않습니다. 이유는 경로의 다음 단계에서 학습자가 다시 관찰하며 찾습니다.

## 절차 흐름

### 공개 단계

| 공개 단계 | 알려 주는 것 | 쓰는 때 |
| --- | --- | --- |
| 관찰 유도 | 예제에서 무엇을 보면 되는지만 가리킴 | 경로의 단계마다 처음 |
| 힌트 | 어디를 보면 답이 나오는지 좁혀 줌 | 학습자가 요청할 때만 |
| 부분 설명 | 현상이나 이유의 일부 | 학습자가 요청할 때만 |
| 전체 설명 | 그 단계의 현상과 이유 전부 | 학습자가 요청할 때만 |

### 전이 표

**관찰 유도 뒤에는 학습자의 반응을 보고 아래 표에서 처리와 다음 위치를 고릅니다.**

| 학습자 반응 | 처리 | 다음 |
| --- | --- | --- |
| "모르겠어" | 관찰해야 했던 현상을 알려 줌 | 경로의 다음 단계 |
| 맞게 설명 | 왜 맞았는지 알려 줌 | 경로의 다음 단계 |
| 틀린 추측 | 추측 과정을 묻고 기대한 현상과 비교해 알려 줌 | 경로의 다음 단계 |
| 안내에 담긴 용어를 되물음 | 요청을 기다리지 않고 그 용어의 설명을 안내에 적힌 순서대로 다시 알려 줌 | 같은 단계에서 반응을 다시 받음 |
| 질문의 의도를 되물음 | 이 단계에서 무엇을 확인하려는지 알려 줌 | 같은 단계에서 반응을 다시 받음 |
| 다른 질문 | 현재 단계의 현상을 알려 주고, 남은 단계를 다음 탐색 후보로 남김 | 새 질문의 설명 경로 |
| 힌트나 부분 설명 요청 | 요청한 공개 단계로 설명 | 같은 단계에서 반응을 다시 받음 |
| 기대한 현상이 나오지 않음 | 새로고침이나 다시 실행처럼 예제 안에서 할 수 있는 확인을 한 번 안내 | 같은 단계에서 반응을 다시 받음 |
| 확인 뒤에도 기대한 현상이 나오지 않음 | 관찰해야 했던 현상을 알려 주고 경로를 멈춤 | [재현되지 않는 예제](example-builder.md#5-재현되지-않는-예제) |

"현상을 알려 준다"는 관찰해야 했던 현상까지만 알려 준다는 뜻입니다. 그 현상이 왜 일어나는지는 경로의 다음 단계에서 다시 관찰 유도부터 시작합니다. 다른 질문으로 넘어갈 때 남은 단계를 기록하는 방법은 [Knowledge Navigator](knowledge-navigator.md)가 정합니다.

학습자가 무엇인가를 되물으면 되묻는 대상이 현재 사전 안내에 담겨 있는지로 세 행을 가릅니다. 안내에 있는 용어를 되물었다면 안내가 전달되지 않은 것이므로, 학습자가 힌트나 설명을 요청하기를 기다리지 않습니다. 안내에 없는 개념을 되물었다면 "다른 질문"으로 처리합니다.

"기대한 현상이 나오지 않음"은 학습자가 결과를 정확히 전했는데 그 결과가 경로 단계의 현상과 다른 경우입니다. 학습자가 현상은 제대로 보고 이유를 잘못 짚은 경우는 "틀린 추측"으로 처리합니다.

### 공개 단계 지정

**학습자가 "자세히 설명해 줘"처럼 공개 단계를 직접 지정하면, 반응과 무관하게 그 단계로 설명합니다.**

전체 설명을 지정했으면 설명한 뒤 경로의 다음 단계로 가고, 힌트나 부분 설명을 지정했으면 같은 단계에서 반응을 다시 받습니다.

## 예외 처리

해당 없음. 공개 단계에 관한 학습자의 요청은 전이 표의 마지막 행과 공개 단계 지정으로 모두 처리합니다.
