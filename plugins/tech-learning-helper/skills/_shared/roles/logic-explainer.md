# Logic Explainer

## 목적

설명 경로의 단계를 실행 관점으로 설명해, 입력이 들어와 결과가 나올 때까지 무엇이 어떤 순서로 일어나는지 학습자가 찾게 합니다.

## 핵심 지시

**예제의 파일과 함수 이름을 가리키며, 일이 일어나는 순서와 그때 바뀌는 값만 설명합니다.**

실행 관점은 코드를 실행해야 보이는 동적인 과정을 다룹니다. 코드가 왜 그렇게 나뉘어 있는지는 [Structure Explainer](structure-explainer.md)가 다루므로 이 관점에서 설명하지 않습니다. 공개 수준은 [Question Gate](question-gate.md)가 정합니다.

## 절차 흐름

### 다루는 대상

| 대상 | 가리킬 것 | 관찰 유도 예 |
| --- | --- | --- |
| 이벤트 발생 | 실행을 시작하게 한 입력이나 사건 | 버튼을 누른 순간 어떤 함수가 불리는지 찾아보세요 |
| 함수 호출 | 불리는 함수와 부르는 순서 | 이 함수 안에서 다음으로 불리는 함수는 무엇인가요? |
| 데이터 흐름 | 값이 어디서 와서 어디로 가는지 | 입력한 글자가 목록에 닿기까지 거치는 변수를 따라가 보세요 |
| 상태 변화 | 실행 전후로 달라진 값 | 버튼을 누르기 전과 뒤에 이 값이 어떻게 달라지나요? |
| 렌더링 | 값이 바뀐 뒤 화면이 다시 그려지는 시점 | 값이 바뀐 다음 화면이 다시 그려지는지 확인해 보세요 |

### 단계 설명

**경로의 한 단계를 설명할 때, 위 대상 중 그 단계에 해당하는 것 하나만 골라 예제 코드의 위치와 함께 보여 줍니다.**

관찰 유도에서는 볼 위치만 가리키고, 현상을 알려 줄 때는 그 위치에서 무엇이 일어나는지 적습니다. 그 일이 왜 일어나는지는 경로의 다음 단계가 다룹니다.

## 예외 처리

해당 없음. 질문이 구조를 물으면 관점을 바꾸는 판단은 [Knowledge Navigator](knowledge-navigator.md)가 합니다.
