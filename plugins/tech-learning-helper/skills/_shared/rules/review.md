# 학습 정리 규칙

## 목적

학습 패키지 하나에서 다룬 질문과 발견한 개념을 그 패키지의 상태 파일에서 모아, 다시 볼 수 있게 보여 줍니다.

## 핵심 지시

**정리를 요청받으면 학습 패키지 하나의 `state.json` 값을 그대로 옮겨 채팅에 보여 줍니다. 새 파일을 만들거나 커밋하지 않습니다.**

모든 값은 아래 표의 파일에서 옮기고, 새로 풀어 쓴 설명이나 요약 문장은 넣지 않습니다. 배운 내용을 자기 말로 정리하는 일은 학습자의 몫이기 때문입니다.

## 절차 흐름

### 1. 정리 대상

**진행 중인 학습이 있으면 지금 학습하는 패키지를, 없으면 [이어 하기 목록](resume.md#3-이어-하기-목록)에서 학습자가 고른 패키지를 정리합니다.**

값은 그 패키지의 `state.json`과 `README.md`에서 읽습니다. 정리할 때마다 새로 파일을 쓰지 않고 다시 읽어 보여 줍니다.

### 2. 값 옮기기

**아래 순서로 값을 옮겨 채팅에 보여 줍니다.**

| 순서 | 옮기는 값 | 읽는 곳 |
| --- | --- | --- |
| 학습 목표 | 패키지의 학습 목표 | 패키지 `README.md`의 `## 학습 목표` |
| 다룬 질문 | 질문, 도달한 개념, 날짜, 기록 파일 링크 | 패키지 `state.json`의 `questions`, `questions.md` |
| 발견한 개념 | 이 패키지에서 발견한 개념 이름 | 패키지 `state.json`의 `discoveredConcepts` |
| 부분 이해 개념 | 개념과 남은 설명 | 패키지 `state.json`의 `partialConcepts` |
| 다음 탐색 후보 | 후보와 이어지는 질문이나 남은 단계 | 패키지 `state.json`의 `nextCandidates` |

| 값 | 옮기는 방법 |
| --- | --- |
| 다룬 질문 | `questions`를 기록 파일 경로의 날짜·순번 순으로 옮김 |
| 도달한 개념(완료한 질문) | `questions.md`에서 같은 질문의 설명 경로를 찾아, 마지막 단계에 적힌 개념 |
| 도달한 개념(진행 중인 질문) | `nextCandidates`에서 같은 질문을 찾아 `미도달(남은 단계 3~4)`처럼 남은 단계를 적음 |
| 발견한 개념 | `discoveredConcepts`를 이름 목록으로 나열(뜻은 별도로 저장하지 않으므로 적지 않음) |
| 부분 이해 개념, 다음 탐색 후보 | `partialConcepts`, `nextCandidates`를 그대로 옮김 |

항목이 없는 값은 `없음`이라고 보여 줍니다.

### 3. 표시

**진행 중인 기록·상태 변경이 있으면 [중단된 변경 커밋](resume.md#5-중단된-변경-커밋)으로 먼저 커밋한 뒤, 정리 내용을 학습자에게 그대로 보여 줍니다.**

## 양식

### 정리 표시 순서

```markdown
# <주제 표시 이름> 학습 정리

## 학습 목표

<패키지 README.md의 학습 목표>

## 다룬 질문

| 질문 | 도달한 개념 | 날짜 | 기록 |
| --- | --- | --- | --- |
| <질문 원문> | <설명 경로의 마지막 개념> | 2026-09-14 | [질문 기록](records/2026-09-14/01-question-slug.md) |
| <끝나지 않은 질문> | 미도달(남은 단계 3~4) | 2026-09-14 | [질문 기록](records/2026-09-14/02-question-slug.md) |

## 발견한 개념

| 개념 |
| --- |
| <개념> |

## 부분 이해 개념

| 개념 | 남은 설명 |
| --- | --- |
| <개념> | <아직 공개하지 않은 부분> |

## 다음 탐색 후보

| 후보 | 이어지는 질문이나 남은 경로 단계 |
| --- | --- |
| <개념이나 질문> | <어디서 이어지는가> |
```

항목이 없는 절에는 표 대신 `없음`을 적습니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 정리할 패키지에 기록 파일이 없음 | `## 다룬 질문`에 `없음`을 적고 나머지 절을 정리 |
