# 학습 정리 규칙

## 목적

학습 패키지 하나에서 다룬 질문과 발견한 개념을 저장된 파일에서 모아, `summary.md` 한 파일로 다시 볼 수 있게 합니다.

## 핵심 지시

**정리를 요청받으면 학습 패키지 하나의 `summary.md`를 저장된 파일의 값으로 덮어쓰고, 검증 스크립트를 통과시킨 뒤 `review` 커밋을 남깁니다.**

모든 값은 아래 표의 파일에서 옮기고, 새로 풀어 쓴 설명이나 요약 문장은 넣지 않습니다. 배운 내용을 자기 말로 정리하는 일은 학습자의 몫이기 때문입니다.

## 절차 흐름

### 1. 정리 대상

**진행 중인 학습이 있으면 지금 학습하는 패키지를, 없으면 [이어 하기 목록](resume.md#3-이어-하기-목록)에서 학습자가 고른 패키지를 정리합니다.**

파일은 `packages/<주제>/summary.md`이며, 정리할 때마다 새로 씁니다.

### 2. 값 옮기기

**`summary.md`의 절마다 아래 파일에서 값을 옮깁니다.**

| 절 | 옮기는 값 | 읽는 곳 |
| --- | --- | --- |
| `## 학습 목표` | 패키지의 학습 목표 | 패키지 `README.md`의 `## 학습 목표` |
| `## 다룬 질문` | 질문, 도달한 개념, 날짜, 기록 파일 링크 | `records/`의 질문 절, `questions.md` |
| `## 발견한 개념` | 이 패키지에서 발견한 개념과 그 뜻 | `state.md`의 `## 발견한 개념`, `knowledge.md` |
| `## 부분 이해 개념` | 개념과 남은 설명 | `state.md`의 `## 부분 이해 개념` |
| `## 다음 탐색 후보` | 후보와 이어지는 질문이나 남은 단계 | `state.md`의 `## 다음 탐색 후보` |

| 값 | 옮기는 방법 |
| --- | --- |
| 다룬 질문 | 기록 파일의 `##` 질문 절을 날짜·순번 순으로 옮기고, `## 실험:` 절은 넣지 않음 |
| 도달한 개념 | `questions.md`에서 같은 질문의 설명 경로를 찾아, 마지막 단계에 적힌 개념 |
| 끝나지 않은 경로의 도달한 개념 | `state.md`의 `## 다음 탐색 후보`에 남은 단계가 적힌 질문은 `미도달(남은 단계 3~4)`처럼 남은 단계를 적음 |
| 발견한 개념 | `state.md`에서 발견한 패키지가 이 패키지인 행만 골라 `knowledge.md`의 뜻을 붙임 |
| 부분 이해 개념, 다음 탐색 후보 | 패키지 열이 없으므로 `state.md`의 표를 그대로 옮김 |

항목이 없는 절에는 `없음`을 적습니다.

### 3. 커밋과 전달

**검증 스크립트를 통과시킨 뒤 `review` 커밋을 남기고, `summary.md`의 내용을 학습자에게 그대로 보여 줍니다.**

```bash
bash <플러그인 경로>/skills/_shared/scripts/validate-learning-repo.sh <저장소>
git -C <저장소> add state.md state.json packages/<주제>/summary.md
git -C <저장소> commit -m "review(<주제>): 학습 정리 갱신"
```

## 양식

### summary.md

```markdown
# <주제 표시 이름> 학습 정리

## 학습 목표

<패키지 README.md의 학습 목표>

## 다룬 질문

| 질문 | 도달한 개념 | 날짜 | 기록 |
| --- | --- | --- | --- |
| <질문 원문> | <설명 경로의 마지막 개념> | 2026-09-14 | [질문 기록](records/2026-09-14/01-question-slug.md) |
| <끝나지 않은 질문> | 미도달(남은 단계 3~4) | 2026-09-14 | [질문 기록](records/2026-09-14/02-question-slug.md) |

## 발견한 개념

| 개념 | 뜻 |
| --- | --- |
| <개념> | <knowledge.md의 뜻> |

## 부분 이해 개념

| 개념 | 남은 설명 |
| --- | --- |
| <개념> | <아직 공개하지 않은 부분> |

## 다음 탐색 후보

| 후보 | 이어지는 질문이나 남은 경로 단계 |
| --- | --- |
| <개념이나 질문> | <어디서 이어지는가> |
```

항목이 없는 절에는 표 대신 `없음`을 적습니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 정리할 패키지에 기록 파일이 없음 | `## 다룬 질문`에 `없음`을 적고 나머지 절을 정리 |
| 새로 쓴 `summary.md`가 이전과 같음 | 커밋하지 않고 정리 내용만 보여 줌 |
| 검증 스크립트가 실패함 | 커밋하지 않고 어긋난 파일을 고친 뒤 다시 검사 |
