# 학습 기록 규칙

## 목적

질의응답을 질문별 파일로 남기고 설명 경로가 끝날 때마다 누적 학습 상태를 확정해, 학습자가 배운 내용을 다시 읽고 정리할 근거를 만듭니다.

## 핵심 지시

**질의응답은 학습 패키지의 날짜 디렉터리 안 질문별 기록 파일에 남기고, 설명 경로 하나가 끝날 때마다 그 패키지의 `state.json`을 갱신해 커밋합니다.**

두 `state.json`(저장소 루트·패키지)의 필드와 새 세션의 재개, 이어 하기 목록은 [학습 재개 규칙](resume.md)이, 상태 값을 그대로 보여 주는 학습 정리는 [학습 정리 규칙](review.md)이 정합니다.

## 절차 흐름

### 1. 질의응답 기록

**일반 답변은 `save-turn`, 설명 경로를 끝내는 답변은 `finish-question`으로 기록과 상태를 한 번에 저장합니다. 입력은 [학습 상태 명령](store.md#저장-입력)을 따릅니다.**

새 질문이 나오면 [Knowledge Navigator](../roles/knowledge-navigator.md)가 `questions-store.sh toc`로 같은 뜻의 질문이 이미 등록됐는지 판단한 결과에 따라 아래처럼 기록 파일과 질문 항목을 정합니다.

| 발견한 것 | 할 일 |
| --- | --- |
| 등록된 질문이 없음 | 그날 디렉터리가 없으면 만들고, 그 안에 다음 순번의 `NN-question-slug.md`를 만듦. 이 경로로 Example Builder가 `questions-store.sh add`를 부르고, 출력된 `id`를 저장 요청의 `questionId`로 전달 |
| 같은 뜻의 질문이 등록돼 있음 | 새 파일을 만들지 않고 그 항목의 `record`에 이어 적음. 항목이 `status: 완료`면 `questions-store.sh start <패키지> <id>`로 `진행`으로 되돌리고, 그 `id`를 저장 요청의 `questionId`로 전달 |

날짜는 학습자 컴퓨터의 오늘 날짜입니다. 파일의 첫 줄은 `# YYYY-MM-DD`로 두고, 질문 원문과 학습자·설명을 기록합니다. 같은 질문의 설명 경로와 실험은 하나의 파일에 둡니다. 기존 `records/YYYY-MM-DD.md`는 읽기 호환 대상으로만 처리합니다.

| 규칙 | 판정 |
| --- | --- |
| 설명 전문 | 학습자에게 보여 준 설명을 줄이거나 고쳐 쓰지 않았습니다 |
| 표·코드 보존 | 설명 속 표·코드 블록·목록이 기록에도 그대로 있습니다 |
| 가리키는 대상 | `이 표`, `위 로그`가 가리키는 대상이 기록 안에 있습니다 |
| 실행 결과 | 설명이 기댄 실행 결과는 필요한 줄을 코드 블록으로 옮겼습니다 |
| 학습자 원문 | 학습자의 말은 입력한 문장 그대로입니다 |
| 인용문 | 학습자의 말은 줄마다 `> `를 붙인 인용문입니다 |
| 발화 이름 | `**학습자**`, `**설명(<괄호>)**`가 한 줄을 따로 차지합니다 |
| 설명의 괄호 | 공개 단계를 적고, 관찰해야 했던 현상을 알려 준 설명은 `현상`, 실험을 안내한 설명은 `실험`을 적습니다 |
| 예제 파일 링크 | 패키지 파일은 기록 파일 기준 상대 링크로 겁니다 |

인용문과 발화 제목의 줄바꿈은 스크립트가 처리합니다. 실험 발화는 `type: 실험`으로 전달하며, 대상 질문의 실험 절도 스크립트가 추가합니다.

학습자가 설명 경로 도중 다른 질문을 하면, 그 질문은 다음 순번의 새 기록 파일에만 적습니다. 이전 파일에는 학습자 줄 없이 현재 단계의 현상 설명을 이어 적습니다. 새 질문 바로 뒤에 현상 설명이 오면, 그 설명이 새 질문의 답으로 읽히기 때문입니다.

### 2. 설명 경로 종료

**설명 경로 하나가 끝나면 질문 항목을 완료로 바꾸고 패키지 `state.json`과 저장소 `state.json`의 인덱스를 갱신한 뒤, 검증 스크립트를 통과시키고 `learn` 커밋을 남깁니다.**

마지막 발화, 이번에 공개한 개념, 부분 이해와 다음 후보를 `finish-question`에 함께 전달합니다. 스크립트가 질문 완료와 두 상태 파일의 개념·활동 날짜를 갱신합니다. `save-turn`이나 `questions-store.sh complete`를 같은 응답에 따로 호출하지 않습니다.

스크립트는 완료한 질문을 가리키는 `resume` 후보를 지웁니다. 경로에 다루지 못한 단계가 남은 채 완료하면, 그 단계는 [Knowledge Navigator의 다루지 못한 단계](../roles/knowledge-navigator.md#다루지-못한-단계)에 따라 `kind: new` 후보로 다음 후보에 넣습니다.

```bash
bash <플러그인 경로>/skills/_shared/scripts/validate-learning-repo.sh <저장소>
git -C <저장소> add state.json packages/<주제>/state.json packages/<주제>
git -C <저장소> commit -m "learn(<주제>): <질문 요약> 탐색"
```

검사에 실패하면 커밋하지 않고 어긋난 파일을 고친 뒤 다시 검사합니다.

## 커밋 규칙

| 커밋 시점 | 메시지 형식 | 포함 파일 |
| --- | --- | --- |
| 예제를 처음 넣었을 때 | `example(<주제>): <예제 요약> 추가` | 패키지의 예제와 `README.md`, `source.md` |
| 재현되지 않는 예제를 고쳤을 때 | `example(<주제>): <수정 요약> 수정` | 바뀐 예제와 `README.md` |
| 설명 경로 하나가 끝났을 때 | `learn(<주제>): <질문 요약> 탐색` | 기록 파일, 저장소 `state.json`, 패키지 `state.json`, `questions.json` |
| 코드 변경형 실험이 끝났을 때 | `learn(<주제>): <질문 요약> 실험` | 바뀐 예제 코드, 기록 파일, 저장소 `state.json`, 패키지 `state.json` |
| 구형 질문 파일을 옮겼을 때 | `learn(<주제>): 질문 파일 구조 이전` | `questions.json`, 패키지 `state.json`, 지운 `questions.md` |
| 학습 정리를 마쳤을 때 | 해당 없음(새 파일을 만들지 않음) | 해당 없음 |
| 다음 학습 시작 때 커밋되지 않은 변경이 있을 때 | `learn(<주제>): 중단된 탐색 기록` | 커밋되지 않은 기록·상태 파일 |

괄호 안에는 학습 패키지 이름을 넣어 `git log`로 주제별 이력을 걸러 낼 수 있게 합니다. 설명은 한국어 명사형으로 끝냅니다. `learn` 커밋에 저장소 `state.json`을 함께 담아야 다음 세션이 남은 상태 변경을 중단된 탐색으로 오인하지 않습니다. 각 커밋의 절차는 아래 문서에 있습니다.

| 커밋 | 절차 |
| --- | --- |
| `example` 추가 | [학습 작업 공간 규칙](workspace.md#7-example-커밋) |
| `example` 수정 | [Example Builder의 재현되지 않는 예제](../roles/example-builder.md#5-재현되지-않는-예제) |
| `learn` 탐색 | 이 문서의 2절 |
| `learn` 실험 | [Experiment Designer](../roles/experiment-designer.md#실험-커밋) |
| 중단된 탐색 기록 | [학습 재개: 중단된 변경 커밋](resume-commit.md) |
| 질문 파일 구조 이전 | [학습 재개 규칙의 패키지 재개](resume.md#3-패키지-재개) |

## 양식

패키지 `state.json`의 필드와 값 구성은 [학습 재개 규칙의 양식](resume.md#패키지-statejson)을 따릅니다. `discoveredConcepts`·`partialConcepts`·`nextCandidates`에 항목이 없으면 빈 배열로 둡니다. 질문 목록은 패키지 `state.json`이 아니라 `questions.json`에 있습니다.

### 기록 파일

기록 파일을 처음 만들 때 아래 머리글만 준비합니다. 이후 발화는 저장 명령으로 추가합니다.

```markdown
# YYYY-MM-DD

## 질문

> <질문 원문>

- 관점: 실행
- 질문 ID: <질문 ID>
```

관점은 `구조`나 `실행`이며, 두 줄 모두 `- ` 불릿으로 적습니다. 구형 질문을 옮기는 `questions-store.sh migrate`가 이 표기에 기대어 관점을 읽습니다. 설명 전문과 코드·표·목록, 학습자 원문을 그대로 전달하고 기록 파일을 읽는 데 필요한 실행 결과도 포함합니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 설명 경로 도중 세션이 끝남 | 다음 학습 시작 때 [학습 재개: 중단된 변경 커밋](resume-commit.md)으로 커밋되지 않은 변경을 먼저 커밋 |
| 검증 스크립트가 실패함 | 커밋하지 않고 어긋난 파일을 고친 뒤 다시 검사 |
