# learn

## 역할과 목적

`learn`은 동작하는 예제에서 학습을 시작하고, 학습자의 질문에 따라 설명 경로를 한 단계씩 따라가며 원리를 찾게 합니다. 이 절차가 전체 학습을 조율하고, 세부 판단은 역할 문서와 규칙 문서에 맡깁니다. 학습자는 무엇을 배울지 정하고, AI는 예제 준비·질문·기록을 맡습니다.

## 실행 원칙

**학습의 시작과 진행은 [`session.md`](../_shared/rules/session.md)를 따릅니다.**

## 참조 문서 규칙

이 문서가 `learn`의 실행 절차를 정하는 기준 문서입니다. 아래 표의 시점에 지정한 문서만 읽고, 나머지 규칙 문서와 역할 문서는 `session.md`의 참조 문서 표가 정한 시점에 읽습니다.

| 문서 | 맡는 일 | 읽는 시점 |
| --- | --- | --- |
| [`rules/store.md`](../_shared/rules/store.md) | 공용 조회·저장 명령 | 첫 상태 조회·저장 시 |
| [`rules/session.md`](../_shared/rules/session.md) | 시작 절차, 목표 판정, 질문 배정, 경로 마무리 | 호출하자마자 |
| [`roles/question-gate.md`](../_shared/roles/question-gate.md) | 공개 단계와 전이 표 | 첫 설명을 할 때 |

## 실행 절차

1. [시작 절차](../_shared/rules/session.md#시작-절차)에 따라 학습을 준비합니다.
2. 새 학습이면 예제를 실행해 보게 한 뒤 [관찰 유도](../_shared/roles/question-gate.md#공개-단계)로 시작합니다. 이어 하는 학습은 복원한 단계에서 재개합니다.
3. 이후 질문과 경로 종료는 `session.md`의 [질문 유형별 배정](../_shared/rules/session.md#질문-유형별-배정)과 [경로 마무리](../_shared/rules/session.md#경로-마무리)를 따릅니다.

## 경계

- 학습자가 `/learn`으로 호출하지 않은 질문이나 코드 작업에는 이 스킬을 쓰지 않습니다.
- 학습 폴더와 범위 밖 기능의 경계는 `session.md`를 따릅니다.
