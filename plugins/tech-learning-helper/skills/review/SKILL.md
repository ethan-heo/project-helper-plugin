# review

## 역할과 목적

`review`는 학습 패키지 하나에서 무엇을 배웠는지 한 파일로 모아 보여 주는 단축키입니다. 학습자는 `/tech-learning-helper:review`로 부릅니다. Claude Code에는 코드 리뷰를 하는 내장 `/review`가 있어서, `/review`만 입력하면 이 스킬 대신 내장 명령이 실행됩니다. 학습 상태는 `state.md`에, 질의응답은 날짜별 기록 파일에 흩어져 있으므로, 그 값을 옮겨 패키지의 `summary.md`에 남깁니다.

## 실행 원칙

**정리는 [`record.md`](../_shared/rules/record.md)의 학습 정리 절을 따르고, 저장된 파일에 있는 값만 옮깁니다.**

새로 풀어 쓴 설명이나 요약 문장은 넣지 않습니다. 배운 내용을 자기 말로 정리하는 일은 학습자의 몫입니다. 정리를 마친 뒤 학습자가 다음 탐색 후보를 고르면 [`session.md`](../_shared/rules/session.md)의 절차로 학습을 이어 갑니다.

## 참조 문서 규칙

이 문서가 `review`의 실행 절차를 정하는 기준 문서입니다. 아래 표의 시점에 지정한 문서만 읽습니다.

| 문서 | 맡는 일 | 읽는 시점 |
| --- | --- | --- |
| [`rules/session.md`](../_shared/rules/session.md) | 시작 절차, 질문 배정, 경로 마무리 | 진행 중인 학습이 없을 때와 정리 뒤 학습을 이어 갈 때 |
| [`rules/workspace.md`](../_shared/rules/workspace.md) | 설정 파일과 학습 폴더 | 진행 중인 학습이 없을 때 |
| [`rules/record.md`](../_shared/rules/record.md) | 이어 하기 목록, 중단된 변경 커밋, 상태 파일, 학습 정리, `review` 커밋 | 정리할 학습을 고를 때와 정리할 때 |
| [`roles/knowledge-navigator.md`](../_shared/roles/knowledge-navigator.md) | 끝나지 않은 경로와 다음 탐색 후보 | 경로 도중에 불렸을 때와 정리가 끝날 때 |

## 실행 절차

**진행 중인 학습**은 `state.json`에 `sessionStatus: in_progress`와 현재 패키지가 저장된 상태를 뜻합니다.

| 호출 상황 | 할 일 |
| --- | --- |
| 진행 중인 학습이 있음 | 지금 학습하는 패키지를 정리 |
| 진행 중인 학습이 없음 | `session.md`의 재개 상태 확인과 목록 선택 뒤 고른 패키지를 정리 |
| 학습 폴더에 기술 저장소가 하나도 없음 | 정리할 학습이 없다고 알리고 끝냄. 저장소를 만들지 않음 |
| 설명 경로 도중에 호출 | 현재 단계의 현상을 알려 주고, 남은 단계를 다음 탐색 후보로 남긴 뒤 정리 |

진행 중인 학습이 없으면 아래 네 단계를 거칩니다. 저장소와 패키지를 새로 만들거나 예제를 준비하지 않으므로, 정리하려고 `example` 커밋을 남기는 일도 없습니다.

1. **학습 폴더를 확인한다** — `session.md`의 1단계를 따릅니다.
2. **정리할 학습을 고른다** — 기술 이름 없이 부르면 기술 저장소 목록에서, 기술 이름과 함께 부르면 학습 패키지 목록에서 고르게 합니다(`record.md`의 이어 하기 목록). 저장소 목록에서 고르면 그 저장소의 마지막 학습 패키지를 정리합니다.
3. **중단된 변경을 커밋한다** — 커밋되지 않은 기록·상태 변경이 있으면 `record.md` 2절에 따라 "중단된 탐색 기록"으로 먼저 커밋합니다. 그래야 `summary.md`가 가리키는 기록 파일이 이력에 남습니다.
4. **학습 상태를 읽는다** — `session.md`의 5단계를 따릅니다.

설명 경로 도중에 부르면 Question Gate 전이 표의 "다른 질문"과 똑같이 처리합니다. 원래 경로의 남은 단계는 `state.md`의 `## 다음 탐색 후보`에 남깁니다(`knowledge-navigator.md`).

### 정리

`record.md`의 학습 정리 절에 따라 `summary.md`를 쓰고, 검증 스크립트를 통과한 뒤 `review(<주제>): 학습 정리 갱신` 커밋을 남깁니다. 다 쓴 `summary.md`는 학습자에게 그대로 보여 줍니다.

### 정리 뒤

정리를 마치면 `summary.md`의 `## 다음 탐색 후보`에서 2~3개를 번호로 제시합니다. 학습자가 후보를 고르면 `session.md`의 6단계로 예제와 지식을 준비한 뒤, 그 후보의 설명 경로를 관찰 유도로 시작합니다. 이후 질문은 `session.md`의 배정 표로 받습니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 정리할 패키지에 기록 파일이 없음 | `## 다룬 질문`에 `없음`을 적고 나머지 절을 정리(`record.md`) |
| 검증 스크립트가 실패함 | 커밋하지 않고 어긋난 파일을 고친 뒤 다시 검사 |

## 경계

- 학습자가 `/tech-learning-helper:review`로 호출하지 않은 질문이나 코드 작업에는 이 스킬을 쓰지 않습니다.
- 학습자 대신 배운 내용을 글로 쓰지 않습니다. 학습 폴더와 범위 밖 기능의 경계는 `session.md`를 따릅니다.
