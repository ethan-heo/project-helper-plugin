# 계층 경로와 ID 승계

## 목적

하위 PRD를 어디에 두고 어떤 ID를 붙일지, 상위 문서에 어떻게 연결할지 정한다.

## 핵심 지시

계층마다 디렉터리를 중첩하고, 디렉터리와 파일 이름에는 그 계층에서 담당하는 ID 한 마디만 쓴다.

## 경로 규칙

분해한 상위 PRD는 자기 이름의 디렉터리 안으로 들어가 `README.md`가 되고, 하위 PRD는 그 옆에 놓인다. 한 계층의 문서가 디렉터리 하나에 모인다.

| 계층 | 경로 | 문서 안의 요구사항 ID |
| --- | --- | --- |
| 1 | `prds/2026-09-02-create-sub-prd/README.md` | `R1`~`R12` |
| 2 | `prds/2026-09-02-create-sub-prd/R3-분해절차.md` | `R3-1`, `R3-2` |
| 3 | `prds/2026-09-02-create-sub-prd/R3-분해절차/README.md` | `R3-1`, `R3-2` |
| 3 | `prds/2026-09-02-create-sub-prd/R3-분해절차/R1-묶음제안.md` | `R3-1-1`, `R3-1-2` |

3계층을 만들 때는 `R3-분해절차.md`를 `R3-분해절차/README.md`로 옮긴 뒤 그 옆에 하위 문서를 만든다. 아직 분해하지 않은 문서는 디렉터리를 만들지 않고 파일 하나로 남는다.

하위 문서의 이름은 `<그 계층의 ID 한 마디>-<주제>` 형식이다. 전체 ID는 경로를 따라가며 복원한다. 한 묶음이 여러 요구사항을 맡으면 이름의 ID 자리에 대표 ID를 쓰고, 담당 ID 전부는 문서 안에 적는다.

### 상위 문서를 옮기는 순서

| 순서 | 할 일 |
| --- | --- |
| 1 | 상위 문서 이름으로 디렉터리를 만든다 |
| 2 | 상위 문서를 그 디렉터리 안의 `README.md`로 옮긴다 |
| 3 | 상위 문서 안의 상대 경로 참조를 새 위치 기준으로 고친다 |
| 4 | 한 계층 위의 문서가 이 문서를 가리키고 있으면 그 링크도 새 경로로 고친다 |

## ID 승계

하위 문서의 요구사항 ID는 상위 ID를 이어받아 뒤에 한 마디를 붙인다. `R3`을 담당하는 문서의 요구사항은 `R3-1`, `R3-2`가 된다.

## 상위 출처 표기

하위 문서는 `마지막 갱신` 아래에 아래 한 줄을 둔다.

```
**상위 PRD** — [<상위 문서 이름>](<상대 경로>) · 담당 요구사항 R3, R5
```

담당 요구사항이 여럿이면 ID를 쉼표로 나열한다.

## 상위 요구사항 표 표기

상위 PRD의 요구사항 표에 `하위 PRD` 열을 마지막에 추가하고, 각 행에 담당 문서 링크를 넣는다.

| ID | 구분 | 요구사항 | 충족 판정 | 하위 PRD |
| --- | --- | --- | --- | --- |
| R3 | 필수 | <요구사항> | <판정 기준> | [R3-분해절차](R3-분해절차.md) |

요구사항 서술은 지우지 않는다. 상위만 읽어도 전체 범위가 보여야 한다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 대상 경로에 하위 디렉터리가 이미 있다 | 덮어쓰지 않고 기존 배정을 보여준 뒤 이어서 진행할지 확인받는다 |
| 대상 문서가 이미 `README.md`이다 | 옮기지 않고 그 디렉터리에 하위 문서를 더한다 |
| 옮길 자리에 다른 `README.md`가 있다 | 덮어쓰지 않고 사용자에게 알린다 |
| 상위 요구사항 표에 `하위 PRD` 열이 이미 있다 | 열을 다시 만들지 않고 빈 행만 채운다 |
| 여러 요구사항을 맡는 묶음의 대표 ID를 정하기 어렵다 | 담당 ID 중 가장 앞선 것을 대표로 쓴다 |

## 근거·예시

파일명에 전체 ID를 누적하면 계층이 깊어질수록 이름이 길어진다. 계층 다섯 단계에서 `R3-1-2-4-1-가중치.md`가 되는 식이다. 디렉터리가 이미 계층을 나타내므로 이름에는 그 계층의 마디 하나만 두어도 경로 전체에서 ID가 복원된다.

상위 문서를 디렉터리 밖에 두면 디렉터리 이름이 가리키는 문서가 정작 그 안에 없다. 계획서가 세 층 구조에서 각 층의 `README.md`로 자기 층을 설명하는 방식과도 어긋난다.
