# 요구사항 구체화

## 목적

하위 PRD를 쓰면서 담당 요구사항을 더 좁은 항목으로 갈라, 상위의 모호한 서술이 그대로 옮겨 가지 않게 합니다.

## 핵심 지시

상위에서 확정된 절은 승계하고, 담당 범위에서 새로 정해야 하는 절만 질의응답으로 채웁니다.

## 절의 승계와 질의 구분

| 절 | 처리 |
| --- | --- |
| 한 줄 요약 | 새로 씁니다. 담당 요구사항이 누구의 무엇을 해결하는지 한 문장으로 씁니다 |
| 배경과 문제 | 상위에서 승계하고, 담당 범위로 좁힌 문제를 한 줄 더합니다 |
| 목적과 목표 | 담당 요구사항의 충족 판정을 근거로 새로 묻습니다 |
| 사용자와 사용 상황 | 묶음의 근거가 된 행만 승계합니다 |
| 요구사항 | 질의응답으로 상위 요구사항을 여러 항목으로 나누고 각각 충족 판정을 적습니다 |
| 범위 밖 | 상위의 제외 항목을 승계하고, 이 계층에서 더 제외할 것을 묻습니다 |
| 제약과 전제 | 상위에서 그대로 승계합니다 |
| 미해결 질문 | 새로 묻습니다 |

승계한 절은 상위의 문장을 그대로 옮깁니다. 요약해 줄이지 않습니다. 계층 사이의 상세도를 맞추기 위해서입니다.

**옮기기 전에 승계할 문장을 [`writing-style.md`](../../_shared/writing-style.md)의 어휘 절로 점검합니다.**

| 점검 결과 | 할 일 |
| --- | --- |
| 고칠 표현이 없음 | 그대로 옮깁니다 |
| 고칠 표현이 있음 | 사용자에게 확인받아 상위를 먼저 고친 뒤 옮깁니다 |

고치지 않고 옮기면 같은 결함이 하위 문서 수만큼 복제됩니다. 하위에서만 고치면 같은 문장이 계층마다 다르게 남습니다.

## 요구사항을 좁히는 질문

| 순서 | 질문 | 넘어갈 조건 |
| --- | --- | --- |
| 1 | 이 요구사항이 성립하려면 무엇이 각각 가능해야 합니까 | 담당 요구사항이 둘 이상의 항목으로 갈렸다 |
| 2 | 각 항목은 무엇을 보면 충족된 줄 압니까 | 모든 항목에 관찰 가능한 충족 판정이 적혔다 |
| 3 | 그중 없으면 성립하지 않는 것은 무엇입니까 | 모든 항목이 필수와 선택 중 하나로 갈렸다 |
| 4 | 이 범위에서 하지 않기로 할 것이 있습니까 | 제외 항목마다 이유가 함께 나왔다 |

열린 질문을 먼저 던집니다. 답변만으로 항목을 가르기 어려우면 선택지 두셋과 각 선택이 만드는 차이를 제시합니다. 선택지가 둘에서 셋이면 `1.`, `2.`, `3.` 형식으로 번호를 붙입니다.

질문과 선택지에는 [질문 예시](../../_shared/questioning-examples.md)에 따라 예시를 붙입니다.

## 구체화 판정

아래를 모두 만족해야 그 하위 PRD의 요구사항 절을 확정합니다.

| 점검 항목 | 통과 기준 |
| --- | --- |
| 서술 이전 | 상위 요구사항의 문장을 그대로 옮겨 적은 항목이 없습니다 |
| 판정 가능성 | 모든 항목에 관찰 가능한 충족 판정이 적혀 있습니다 |
| 구분 | 모든 항목이 필수와 선택 중 하나로 표시되어 있습니다 |
| 범위 | 상위 요구사항이 정한 범위 밖의 항목이 없습니다 |
| ID | 항목의 ID가 상위 ID를 이어받아 매겨져 있습니다 |
| 용어 | 상위가 쓴 대상에 새 이름을 붙인 항목이 없습니다 |

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 상위 요구사항이 더 갈라지지 않음 | 항목을 억지로 늘리지 않고 충족 판정만 구체화한 뒤 그 사실을 알립니다 |
| 승계할 절의 내용이 담당 범위와 맞지 않음 | 승계하지 않고 그 절만 새로 묻습니다 |
| 답변이 구현 방식을 다룸 | PRD의 범위가 아님을 알리고 목적과 요구사항으로 되돌립니다 |
| 사용자가 구체화를 건너뛰자고 요청함 | 절을 비우지 않고 미확정 내용을 `미해결 질문`으로 옮긴 뒤 진행합니다 |

## 근거·예시

나누기만 하고 구체화하지 않으면 문서 수만 늘고 모호한 서술은 그대로 남습니다. 예를 들어 "묶음 후보를 제안하고 사용자가 고른 묶음을 분할 단위로 삼는다"라는 상위 요구사항은 하위에서 세 항목으로 갈립니다. "후보를 무엇에서 만드는가", "후보마다 무엇을 보여주는가", "선택을 어떻게 확정으로 기록하는가"이며, 항목마다 충족 판정을 따로 답니다.
