# PRD 서술 규칙

## 목적

읽는 사람이 한 번 읽고 이해할 수 있는 PRD를 만든다.

## 핵심 지시

한 절은 한 가지만 말하고, 판정할 수 없는 표현을 남기지 않는다.

## 서술 규칙

문체와 표기, 서술 단위의 길이, 용어를 푸는 방식은 [`writing-style.md`](../writing-style.md)를 따른다. 아래는 PRD에만 해당하는 규칙이다.

- 한 문장에는 하나의 주장만 담는다. 접속으로 이어 붙인 문장은 나눈다.
- 판정 기준은 관찰 가능한 것으로 쓴다. "빠르다", "편리하다"처럼 사람마다 다르게 읽히는 표현은 수치나 관찰 가능한 상태로 바꾼다.
- 항목이 셋 이상이면 표로 정리한다. 산문으로 나열하지 않는다.
- 해법과 구현 방식은 쓰지 않는다. 무엇을 왜 만드는지만 다룬다.
- 같은 내용을 두 절에 반복해 적지 않는다. 한 자리에만 두고 나머지는 참조한다.
- 확정하지 못한 내용은 추측으로 메우지 않고 `미해결 질문`으로 옮긴다.

## 확정 전 점검 목록

각 항목의 판정 기준을 그대로 적용한다. 하나라도 불통과이면 확정하지 않는다.

| 점검 항목 | 통과 기준 |
| --- | --- |
| 한 줄 요약 | 이 문장만 읽고 제품이 무엇인지 말할 수 있다 |
| 문제의 구체성 | 문제 서술에 현재 사람들이 겪는 상황이 하나 이상 적혀 있다 |
| 목표의 판정 가능성 | 모든 목표에 관찰 가능한 성공 판정 기준이 붙어 있다 |
| 사용자 특정 | 사용자 항목이 직군이나 상황으로 좁혀져 있고 "모든 사용자"가 아니다 |
| 요구사항 구분 | 모든 요구사항이 필수와 선택 중 하나로 표시되어 있다 |
| 요구사항의 판정 가능성 | 모든 요구사항에 충족 판정 기준이 붙어 있다 |
| 범위 밖의 이유 | 제외 항목마다 이유가 함께 적혀 있다 |
| 해법 혼입 | 구현 방식이나 기술 선택을 지시하는 문장이 없다 |
| 중복 | 같은 내용이 두 절 이상에 반복되지 않는다 |
| 미해결 잔존 | 미해결 질문 절에 남은 항목이 없다 |
| 분량 | 절마다 표 하나 또는 문단 셋 이내로 유지된다 |

## 예외 처리

> 사용자가 미해결 항목을 남긴 채 마무리하기를 요청하면, 확정 대신 초안 상태임을 문서에 표시하고 남은 항목을 그대로 둔다.

## 근거·예시

판정 기준이 없는 목표는 나중에 달성 여부를 두고 다시 논쟁이 열린다. "응답이 빠르다"는 "첫 화면이 2초 안에 표시된다"로 바꾼다.
