# 아키텍처 판단 기준

## 구조 결정의 범위

**둘 이상의 구현 계획에 영향을 주거나 구성 요소 사이의 책임·계약을 바꾸는 결정을 구조 결정으로 봅니다.**

구조 결정은 `create-architecture`에서, 한 계획 안에서 끝나는 세부 구현은 `create-plan`에서 다룹니다.

## PRD 확정 후 안내

**`create-prd`·`create-sub-prd`를 마치면 확정한 문서 루트의 `architecture/`를 확인해 다음 스킬을 안내합니다.**

기존 문서가 있으면 색인·결정 기록·관련 영역을 읽고 새 구조 결정이 필요한지 판단합니다.

| 아키텍처 문서 상태 | 할 일 |
| --- | --- |
| 문서가 없음 | `/create-architecture` 안내 |
| 새 구조 결정이 필요함 | `/create-architecture` 안내 |
| 기존 결정으로 충분함 | `/create-plan` 안내 |
| 판단하기 어려움 | `/create-plan` 안내 |

`create-plan`의 준비 단계에서 다시 판단하므로, 안내를 위해 PRD 작성 절차를 늘리지 않습니다.
