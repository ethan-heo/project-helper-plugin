# 스킬 실행 맥락

## 목적

명시적으로 호출한 스킬에서 후속 입력을 해석하는 기준을 정합니다. 이 문서를 참조하는 스킬에만 적용합니다.

## 입력 해석

**후속 입력은 호출한 스킬의 작업 입력으로 해석하되, 개념이나 사용법만 묻는 질문에는 작업을 진행하지 않고 일반 답변을 제공합니다.**

| 호출한 스킬 | 후속 입력의 용도 | 작업 종료 시점 |
| --- | --- | --- |
| `create-plan` | 계획 작성 | 계획 완료 |
| `impl-plan` | 현재 계획의 구현 | 구현 완료 |
| `create-prd` | PRD 작성 | PRD 확정 |
| `create-sub-prd` | PRD 분해 | 분해 완료 |
| `explain-commit` | 대상 커밋 지정 | 문서 생성 완료 |

작업이 끝나거나 사용자가 다른 스킬 또는 일반 질문을 명시할 때까지 실행 맥락을 유지합니다.

## 계획에 추가 작업 반영

**`create-plan`·`impl-plan`에서 추가 작업을 받으면 현재 계획의 기능과 사용자 흐름에 관련되는지 판단합니다.**

| 추가 작업 | 할 일 |
| --- | --- |
| 현재 계획과 관련됨 | 기존 계획서의 설계·구현 순서·테스트 갱신 |
| 현재 계획과 관련 없음 | 기존 계획서의 `추후 작업`에 기록 |

관련 작업을 반영한 뒤 상태는 `계획 완료`로 유지합니다. `create-plan`에서는 기존 상태가 `진행 중`이나 `완료`여도 같은 방식으로 갱신하고, `impl-plan`에서는 갱신한 순서로 구현을 이어 갑니다.

관련 없는 작업은 현재 구현에 포함하지 않습니다. 추가 요청 없이 설계 전제가 틀린 것으로 드러난 경우에는 `impl-plan`의 [계획 결함 처리](../impl-plan/references/failure.md#계획-결함)를 따릅니다.
