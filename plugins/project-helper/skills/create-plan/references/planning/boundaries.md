# 도메인과 기능 경계

## 목적

계획서를 독립적으로 검증할 수 있는 단위로 나눕니다.

## 핵심 지시

독립 검증 지점마다 기능을 나누고, 다루는 대상이 같은 기능을 도메인으로 묶습니다.

## 절차 흐름

1. 구현 순서의 선행 관계와 독립 검증 지점을 확인합니다.
2. 독립 검증 지점마다 기능 하나를 두고, 다루는 대상이 같은 기능을 도메인으로 묶어 AI가 경계를 제안합니다.
3. 도메인과 기능 이름을 정하고 사용자에게 동의받습니다.

## 예외 처리

검증 지점이나 다루는 대상이 하나이면 기능이나 도메인도 하나입니다. 문서 층위는 [문서 계층](../documents/hierarchy.md)을 따릅니다.
