# 참조 문서 이전 기준

이 문서는 기존 참조 문장을 새 역할별 파일로 옮길 때 사용하는 분류 기준이다.

## 필수 분류

| 기존 문서 | 내용 유형 | 새 문서 | 우선순위 |
| --- | --- | --- | --- |
| `facilitation.md` | 역할과 협업 주체 | `collaboration/roles.md` | 필수 |
| `facilitation.md` | 질문·힌트·선택지 | `collaboration/questioning.md` | 조건부 |
| `facilitation.md` | 승인·축약 요청 | `collaboration/approval.md` | 조건부 |
| `sections.md` | 요약·상태 | `sections/summary.md` | 필수 |
| `sections.md` | 설계 | `sections/design.md` | 필수 |
| `sections.md` | 구현 순서 | `sections/implementation.md` | 필수 |
| `sections.md` | 테스트 | `sections/testing.md` | 필수 |
| `sections.md` | 경계·구조 이전 | `planning/boundaries.md`, `documents/hierarchy.md` | 조건부 |

## 이전 원칙

- 한 문장은 하나의 새 문서에만 정본으로 둔다.
- 여러 문서에 걸친 관계는 원문을 복제하지 않고 참조 경로만 적는다.
- 새 문서에 옮긴 문장은 `필수`, `조건부`, `참고` 중 하나로 분류한다.
- 분류할 수 없는 문장은 임의로 옮기지 않고 검토 대상으로 남긴다.
