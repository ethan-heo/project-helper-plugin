# 문서 계층

## 목적

최상위·도메인·기능 문서의 책임을 나눕니다.

## 핵심 지시

최상위는 도메인, 도메인은 기능, 기능 계획서는 구현 항목과 상태를 관리합니다.

## 절차 흐름

위층부터 README를 만들고 아래층으로 내용을 옮긴 뒤 초안을 삭제합니다.

| 문서 층위 | 남길 내용 |
| --- | --- |
| 최상위 | 도메인·선행 관계·문서 루트·기준 아키텍처 |
| 도메인 | 기능 목록 |
| 기능 계획서 | 설계·구현 항목·테스트·상태 |

상태는 기능 계획서에서만 관리합니다. 최상위와 도메인 문서에는 목록과 판단만 둡니다.

## 예외 처리

기능 하나여도 세 층 구조를 생략하지 않습니다.
