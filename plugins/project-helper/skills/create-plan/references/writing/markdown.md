# Markdown 표현

## 목적

계획서의 정보를 그 역할에 맞는 Markdown 문법으로 표현한다.

## 핵심 지시

내용을 명령·순서·분기·예외·근거·예시로 분류한 뒤 표현을 선택한다.

| 정보의 역할 | 표현 |
| --- | --- |
| 명령 | 굵게 쓴 한 문장 |
| 예외 | 경고 블록 |
| 예시 | 코드 블록 |

목록과 표와 문단 중 무엇을 쓸지는 [`writing-style.md`](../../../_shared/writing-style.md)가 정한다. 이 문서는 계획서에만 해당하는 세 가지를 더한다.

## 예외 처리

표가 비교나 분기를 표현하지 못하면 목록이나 산문으로 바꾼다.
