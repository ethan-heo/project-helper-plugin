# 구현 순서

## 목적

계획을 되돌릴 수 있는 커밋 단위로 나눈다.

## 핵심 지시

구현 항목마다 ID, 대상 위치, 완료 판정을 적고 한 항목을 한 커밋으로 둔다.

항목 줄은 번호 매김 목록으로 쓰고, 완료 판정은 그 아래 하위 목록 줄에 둔다.

```markdown
1. [ ] **DOMAIN-FEATURE-001** <제목> — <무엇을 어디에>
   - 완료 판정: <무엇을 보면 끝난 줄 아는가>
```

완료 판정을 항목 줄에 이어 붙이지 않는다. 설명과 판정 기준이 한 줄에 섞이면 항목을 훑을 때 기준이 눈에 들어오지 않는다.

구현이 끝나면 `impl-plan`이 완료 판정 줄 아래에 `- 기록:` 줄을 붙인다. 두 줄 모두 항목 아래 세 칸 들여쓴 목록이다.

## 절차 흐름

선행 항목부터 의존 관계가 드러나는 순서로 작성한다.

## 예외 처리

무엇을 어디에 할지 정할 수 없는 항목은 확정 전에 다시 설계한다.
