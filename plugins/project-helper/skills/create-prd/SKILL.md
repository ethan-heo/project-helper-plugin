# create-prd

## 역할과 목적

`create-prd`는 무엇을 왜 만드는지를 사용자와의 질의응답으로 확정하고, 그 결과를 PRD 문서 한 편으로 남긴다. 구현 방식은 다루지 않는다. 사용자는 목적과 요구사항의 결정권자이고, AI는 질문·정리·기록을 맡는다.

## 실행 원칙

**답변이 충분해질 때까지 질문하고, 확정되지 않은 것은 미해결로 표시한다.**

사용자가 이 스킬을 명시하면 뒤따르는 답변은 기본적으로 PRD 작성의 입력으로 해석한다. 질문이 스킬의 개념이나 사용법만 묻는 설명 요청이면 작성을 진행하지 않고 일반 답변을 제공한다. 작성 입력으로 이어진 실행 맥락은 PRD가 확정되거나 사용자가 다른 스킬 또는 일반 질문을 명시할 때까지 유지한다.

산출물은 단일 문서 한 편이다. 여덟 절을 넘기지 않고, 절마다 읽는 사람이 한 번에 이해할 수 있는 분량으로 유지한다. 추측으로 빈칸을 메우지 않으며, 확정하지 못한 내용은 `미해결 질문` 절에 남긴다.

요청이 기능 하나의 구현 방식에 관한 것이면 PRD를 만들지 않고 `/create-plan`을 안내한다.

## 참조 문서 규칙

이 문서가 `create-prd`의 실행 지시사항을 정하는 기준 문서다. 작업을 시작할 때 이 문서를 먼저 읽고, 아래 표의 절차에 진입할 때 지정된 참조 문서만 읽는다.

| 문서 유형 | 역할 | 적용 범위 |
| --- | --- | --- |
| `SKILL.md` | 실행 절차와 분기 | `create-prd` 전체 |
| `references/questioning.md` | 카테고리별 질문 설계와 충분성 판정 | 카테고리 순회 |
| `references/writing.md` | 간결성 서술 규칙과 점검 목록 | 절을 쓸 때와 확정 직전 |
| `assets/prd-template.md` | PRD 문서 양식 | 초안을 만들 때 |
| `scripts/validate-prd.sh` | 필수 절과 항목 형식 검증 | 확정 직전 |

참조 문서는 본문에 없는 실행 범위를 추가하지 않는다. 문서 관리 형식은 `docs/documentation-management-guide.md`를 따른다.
