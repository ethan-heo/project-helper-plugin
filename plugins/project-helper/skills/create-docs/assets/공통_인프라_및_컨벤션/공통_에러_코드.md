# 공통 에러 코드

## 에러 응답 형식

모든 도메인이 아래 형식으로 에러를 반환한다.

```json
{
  "code": "<에러 코드>",
  "message": "<사용자에게 보일 메시지>",
  "detail": {}
}
```

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `code` | string | <코드 체계 설명> |
| `message` | string | <언어와 용도> |
| `detail` | object | <언제 채워지는가> |

## 공통 코드 목록

| 상태 코드 | 코드 | 의미 | 발생 조건 |
| --- | --- | --- | --- |
| 400 | `<코드>` | <의미> | <어떤 요청일 때> |
| 401 | `<코드>` | <의미> | <어떤 상태일 때> |
| 403 | `<코드>` | <의미> | |
| 404 | `<코드>` | <의미> | |
| 500 | `<코드>` | <의미> | |
