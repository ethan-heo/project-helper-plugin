# 실패와 중단

## 모호한 항목

무엇을 어디에 할지 정해지지 않은 항목은 추측하지 않고 사용자에게 확인합니다.

## 계획 결함

| 발견한 것 | 할 일 |
| --- | --- |
| 설계의 전제가 바뀐다 | 중단하고 현재 상태를 유지한 채 `create-plan`으로 인계 |
| 전제는 같고 함수 이름 등이 다름 | 구현을 계속하고 기록 줄에 차이 기록 |

차이가 사소해 보여도 설계 전제가 바뀌면 중단합니다.

## 중단 처리

작업 트리가 변경된 상태에서 재개하지 않고, 변경 내용을 확인한 뒤 안전한 작업 상태를 확보합니다.
