# 스킬_실행_맥락(skill-trigger) — 도메인 특화 가이드

## 외부 의존성

| 대상 | 종류 | 용도 |
| --- | --- | --- |
| Claude Code | 실행 환경 | `SKILL.md`의 frontmatter를 읽어 발동을 판정하고 슬래시 명령을 등록한다 |
| Codex | 실행 환경 | 같은 스킬 디렉터리를 `.codex-plugin/plugin.json`의 `skills` 필드로 읽는다 |

두 환경 모두 스킬 파일 자체는 같은 것을 읽는다. 설치 경로의 차이는 [배포와_설치(distribution)](../배포와_설치%28distribution%29/01_도메인_개요.md)에 있다.

### 설정

| 항목 | 값의 출처 | 비고 |
| --- | --- | --- |
| `name` | 각 `SKILL.md`의 frontmatter | 슬래시 명령 이름이 된다 |
| `description` | 각 `SKILL.md`의 frontmatter | 발동 판정의 유일한 근거 |
| `defaultPrompt` | `.codex-plugin/plugin.json`의 `interface` | Codex에서 제시되는 예시 요청 네 줄 |
| 평가 사례 | `evals/trigger-eval.json` | 발동 17건과 근접 요청을 담는다 |

## 핵심 테스트 시나리오

`evals/trigger-eval.json`에는 사례 17건이 있다. `create-plan` 6건, `impl-plan` 4건이 발동을 기대하고, 나머지 7건은 발동하면 안 되는 근접 요청이다.

| ID | 상황 | 기대 동작 |
| --- | --- | --- |
| T1 | "리팩터링 범위가 좀 큰데 순서를 어떻게 잡아야 할지 모르겠어" | `create-plan`이 켜진다 |
| T2 | "계획서 확정됐으니까 구현 시작하자" | `impl-plan`이 켜진다 |
| T3 | "다음 스프린트 계획 좀 잡아줘" | 아무 스킬도 켜지지 않는다. 코드 변경이 아닌 일정 계획이다 |
| T4 | "이 함수 이름 오타 좀 고쳐줘" | 아무 스킬도 켜지지 않는다. 한 단계로 끝나는 수정이다 |
| T5 | "이 버그 왜 나는지 좀 봐줘" | 아무 스킬도 켜지지 않는다. 원인 조사는 계획 단계가 아니다 |
| T6 | 두 실행 스킬에서 후속 작업 질문을 이어간다 | 같은 스킬의 입력으로 계속 처리한다 |
| T7 | 스킬 이름이 들어간 사용법 질문을 던진다 | 실행하지 않고 일반 답변을 제공한다 |

### 실행 방법

```bash
python3 -c "import json; d=json.load(open('evals/trigger-eval.json')); print(len(d['cases']))"
```

발동 여부는 자동으로 판정할 수 없다. 플러그인을 설치한 세션에서 각 질의를 여러 번 던져 어느 스킬이 켜지는지 세는 방식으로 측정한다.

## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 계획 요청에 스킬이 켜지지 않는다 | 요청 표현이 `description`의 발동 조건과 겹치지 않는다 | 슬래시 명령으로 호출하고, 반복되면 그 표현을 `evals/trigger-eval.json`에 사례로 추가한 뒤 `description`을 보완한다 |
| 일정 계획 요청에 `create-plan`이 켜진다 | `description`의 부정 조건이 그 표현을 덮지 못한다 | 사용하지 않을 상황에 해당 표현을 추가한다 |
| 스킬 사용법을 물었는데 작업이 시작된다 | 설명 요청 예외가 적용되지 않았다 | 질문임을 밝히고 다시 묻는다. 반복되면 실행 원칙의 문장을 점검한다 |
| 작업 도중 다른 스킬로 넘어간다 | 사용자가 다른 스킬을 명시했거나 작업이 끝난 것으로 판정되었다 | 원래 스킬을 다시 명시해 맥락을 연다 |
| 슬래시 명령이 목록에 없다 | 플러그인이 설치되지 않았거나 세션이 갱신되지 않았다 | 재설치 후 세션을 다시 시작한다 |
| 두 스킬이 같은 요청에서 번갈아 켜진다 | 두 `description`의 경계가 겹친다 | 각 스킬의 `경계` 절에 인계 조건을 명시하고 부정 조건을 나눈다 |
