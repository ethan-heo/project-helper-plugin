# 요구사항_정의(create-prd) — API 명세

## 엔드포인트 목록

| 메서드 | 경로 | 설명 | 인증 |
| --- | --- | --- | --- |
| `호출` | `/create-prd` | 여덟 카테고리의 질의응답으로 PRD를 작성한다 | 불필요 |
| `자동 발동` | 자연어 요청 | "PRD 쓰자", "요구사항 정의부터 하자" 같은 요청에서 켜진다 | 불필요 |
| `실행` | `scripts/validate-prd.sh <PRD 파일>` | 필수 절과 요구사항 표기, 미해결 잔존을 검사한다 | 불필요 |

## `/create-prd`

제품이나 프로젝트 단위의 요구사항을 확정할 때 호출한다. 요청의 대상이 기능 하나의 구현 방식이면 작성을 시작하지 않고 `/create-plan`을 안내한다.

### 요청

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 명령 인자 | 제품 설명 | string | 아니오 | 무엇을 만들려는지. 비어 있으면 첫 카테고리에서 묻는다 |
| 대화 | 카테고리별 답변 | string | 예 | 여덟 카테고리의 질문에 대한 답변 |

```
/create-prd 사내 회의록을 자동으로 정리해 주는 도구를 만들려고 한다
```

### 응답

산출물은 여덟 절을 가진 PRD 파일 한 편이다.

```markdown
## 요구사항

| ID | 구분 | 요구사항 | 충족 판정 |
| --- | --- | --- | --- |
| R1 | 필수 | 회의 녹취에서 결정 사항만 추려 목록으로 만든다 | 30분 분량 녹취에서 결정 사항 목록이 5분 안에 생성된다 |
| R2 | 선택 | 참석자별 후속 작업을 분리해 표시한다 | 후속 작업이 담당자 이름과 함께 표시된다 |
```

### 에러 코드

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| 해당 없음 | 범위 이탈 | 요청이 기능 하나의 구현 방식이다. `/create-plan`으로 안내하고 종료한다 |
| 해당 없음 | 카테고리 미충족 | 넘어갈 조건을 만족하지 못했다. 같은 카테고리에서 질문을 이어간다 |
| 해당 없음 | 확정 거부 | 미해결 질문이 남아 있거나 점검 목록의 항목이 불통과다 |

공통 에러 응답 형식은 [`공통_에러_코드.md`](../../공통_인프라_및_컨벤션/공통_에러_코드.md)를 참조한다.

## `scripts/validate-prd.sh <PRD 파일>`

확정 직전에 실행한다. `grep`으로 절 제목과 요구사항 표기를 검사하고, `미해결 질문` 절 이후에 남은 표 행 수를 센다.

### 요청

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 인자 1 | PRD 파일 | path | 예 | 파일이 없으면 즉시 종료한다 |

```bash
bash plugins/project-helper/skills/create-prd/scripts/validate-prd.sh docs/prds/2026-08-31-meeting-notes.md
```

### 응답

```
PRD 검증 통과: docs/prds/2026-08-31-meeting-notes.md
```

### 에러 코드

| 상태 코드 | 코드 | 발생 조건 |
| --- | --- | --- |
| 1 | `<절 이름> 절이 없습니다.` | 여덟 절 가운데 하나라도 `## <절 이름>`과 정확히 일치하지 않는다 |
| 1 | `사용자 검토 표시가 남아 있습니다.` | `<!-- 사용자 검토 필요 -->`가 있다 |
| 1 | `요구사항 항목이 필수 또는 선택으로 표시되어 있지 않습니다.` | `\| R1 \| 필수 \|` 형식의 행이 하나도 없다 |
| 1 | `미해결 질문이 N건 남아 있습니다.` | `미해결 질문` 절의 표에 머리글 외의 행이 남아 있다 |
| 1 | `<경로> 파일이 없습니다.` | 인자가 가리키는 파일이 없다 |

## 이벤트 메시징

해당 없음. PRD 확정은 이벤트로 알려지지 않는다. 다음 단계인 `create-plan`으로의 인계는 확정 시점에 사용자에게 안내하는 방식으로만 이루어진다.
