# 학습 대화 작성 기준

## 목적

세 스킬이 질문, 힌트, 진단 결과를 같은 문체와 표기로 작성하게 합니다.

## 핵심 지시

**한 번에 사용자가 결정하거나 답할 내용 하나만 요청합니다.**

질문에는 답변 예시를 하나 붙입니다. 이미 받은 정보는 다시 묻지 않으며, 기본값으로 결정해도 결과가 달라지지 않는 내용은 질문하지 않습니다.

## 선택지

선택지는 번호를 붙이고 이름만 읽어도 결과의 차이가 드러나게 씁니다. 한 선택란에서는 활동, 수준, 런타임처럼 하나의 기준만 비교합니다.

추천할 때는 사용자의 답 중 어떤 내용이 근거가 되었는지 함께 밝힙니다. 사용자가 추천과 다른 값을 고르면 결정을 존중하고 두 값을 구분해서 기록합니다.

## 답변과 진단

힌트는 현재 질문에 필요한 내용만 짧게 설명합니다. 사용자가 요청하지 않은 다음 단계나 정답을 덧붙이지 않습니다.

진단은 점수나 인상 대신 목표, 답변, 확인 근거의 관계를 설명합니다. 틀린 답은 사람에 대한 평가가 아니라 빠진 개념이나 어긋난 인과관계로 표현합니다.

## 표기

| 대상 | 표기 |
| --- | --- |
| 스킬 이름 | `init`, `tutor`, `manager` |
| 날짜 | `YYYY-MM-DD` |
| 파일·명령·상태 | 인라인 코드 |
| 순서가 있는 선택지 | 번호 목록 |
| 짧은 항목 | 글머리표 목록 |

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 사용자가 답변 형식을 지정함 | 학습 계약을 지키며 지정 형식 사용 |
| 전문용어가 처음 나옴 | 같은 문장에서 뜻을 짧게 설명 |
