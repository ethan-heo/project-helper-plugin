# 복습 진단과 일정

## 목적

완료된 기록의 목표별 기준과 질문 이력만 사용해 복습을 진단하고 다음 학습을 제안합니다.

## 대상

**`status: completed`인 기록만 복습 대상으로 고릅니다.**

예제 폴더의 코드, `TASK.md`, `PLAN.md`는 열지 않습니다. 기록의 학습 목표와 진단 기준, 질문 이력, 배운 내용, 복습 이력만 읽습니다.

## 복습 일정

기본 복습일은 `completed_at`의 날짜로부터 1일, 3일, 7일, 14일 뒤입니다. 재학습이 필요한 목표가 생기면 실행일 다음 날을 `next_supplemental_review_at`에 기록합니다.

**같은 날짜의 기본 복습과 보충 복습은 한 번으로 합칩니다.**

| 일정 상태 | 할 일 |
| --- | --- |
| 기본 복습만 도래 | 전체 목표 질문 |
| 보충 복습만 도래 | 재학습 목표 질문 |
| 같은 날 둘 다 도래 | 전체 목표를 묻고 이력 한 행 기록 |
| 기본 복습 여러 건이 밀림 | 가장 늦은 기본 일정 한 건 진행 |

보충 목표는 같은 날의 기본 질문에 빠짐없이 포함합니다. 합친 복습을 마치면 기본 일정과 보충 일정을 모두 수행한 것으로 처리합니다.

## 질문

**목표마다 필수 개념·필수 근거·대표 오개념을 확인할 질문 하나를 만듭니다.**

질문에는 예시와 힌트를 붙이지 않습니다. 앞선 배운 내용의 문장을 재사용하지 않습니다. 목표가 여러 개이면 한 번에 하나씩 묻습니다.

## 진단

**사용자의 답과 목표별 진단 기준을 공통 학습 모델의 세 결과로 판정합니다.**

질문 이력의 최대 도움 단계와 해결 근거를 보조 근거로 사용합니다. 답이 진단 기준을 충족해도 같은 목표의 최대 단계가 4나 5이면 도움 이력을 진단 근거에 남깁니다.

대표 오개념이 답에 남아 있으면 맞는 용어가 일부 포함되어도 재학습이 필요한 결과로 판정합니다. 근거가 부족하면 추측하지 않고 빠진 근거 하나를 질문합니다.

## 기록과 다음 학습

복습 이력 한 행에는 예정일, 실행일, 질문, 목표별 진단, 기본·보충 병합 여부를 기록합니다. 같은 날짜의 병합 복습은 행 하나만 추가합니다.

재학습이 필요한 목표가 있으면 다음 날 보충일을 기록하고 그 목표부터 다른 상황의 학습을 제안합니다. 그렇지 않고 부분 이해 목표가 있으면 해당 목표부터 같은 수준의 다른 활동을 제안합니다. 모든 목표가 독립 설명이면 다음 수준의 새 주제를 제안하며 숙련은 같은 수준을 유지합니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 완료 시각이 없음 | 기록 오류 안내 후 대상 제외 |
| 목표별 진단 기준이 없음 | 추측하지 않고 기록 오류 안내 |
| 복습 답변을 건너뜀 | 해당 목표를 재학습 필요로 기록 |
| 보충일 형식이 잘못됨 | 대상 제외와 잘못된 필드 안내 |
| 기록 쓰기 실패 | 진단을 저장한 것처럼 알리지 않음 |
