# manager

## 역할과 목적

`manager`는 완료된 예제에서 배운 내용을 사용자에게 받아 적고, 시간이 지난 뒤 목표별 질문으로 이해 수준을 진단합니다. 진단 결과에서 다음 복습과 학습을 제안합니다.

사용자는 설명과 복습의 주체이고, AI는 대상 선정·질문·진단·기록을 맡습니다.

## 실행 원칙

**사용자가 호출했을 때만 완료된 기록을 읽고, 코드나 과제 문서 없이 복습합니다.**

## 부르는 위치

학습 공간에서만 부릅니다. 학습 공간은 예제 폴더들과 `.study/records/`가 함께 놓인 디렉터리입니다.

예제 폴더 안에서 부르면 진단하지 않고 학습 공간에서 다시 부르도록 안내합니다.

## 읽는 것과 쓰는 것

| 대상 | 권한 |
| --- | --- |
| 완료된 기록의 목표·진단 기준·질문 이력 | 읽기만 함 |
| 완료된 기록의 배운 내용·복습 이력 | 읽고 씀 |
| `next_supplemental_review_at` | 읽고 씀 |
| 예제 폴더의 코드·`TASK.md`·`PLAN.md` | 읽지 않음 |

## 실행 절차

### 1. 완료된 기록을 고릅니다

**기록 계약을 확인한 뒤 `status: completed`인 기록만 목록에 넣습니다.**

| 기록 상태 | 할 일 |
| --- | --- |
| `completed`이고 배운 내용이 비어 있음 | 배운 내용 기록 후보 |
| `completed`이고 복습일이 지남 | 복습 후보 |
| `preparing`, `ready`, `in_progress` | 목록에서 제외 |

후보가 하나이면 바로 진행합니다. 여러 개이면 표시 이름, 할 일, 예정일을 보이고 하나를 선택받습니다. 후보가 없으면 다음 기본 복습일과 남은 일수를 알립니다.

### 2. 배운 내용을 받아 적습니다

**배운 내용이 비어 있으면 목표를 하나씩 보이고 사용자의 설명을 받습니다.**

예시나 힌트를 붙이지 않습니다. 설명을 다듬거나 정답으로 고쳐 쓰지 않고 사용자의 표현을 목표 ID 아래에 그대로 기록합니다.

기억나지 않는다고 답하면 그 말을 그대로 남깁니다. 코드를 보고 답했다고 알리면 그 사실도 함께 기록합니다.

### 3. 복습 일정을 계산합니다

**`review.md`로 기본 복습과 보충 복습의 도래 여부를 판정합니다.**

기본 일정은 완료 뒤 1·3·7·14일입니다. `next_supplemental_review_at`과 기본 일정이 같은 날이면 한 번의 복습으로 합칩니다.

한 예제에서 여러 기본 일정이 밀렸으면 가장 늦은 일정 하나만 실행합니다. 합친 복습은 목표 전체를 묻고 이력은 한 행만 남깁니다.

### 4. 목표별 질문을 냅니다

**필수 개념·필수 근거·대표 오개념을 확인할 질문을 목표마다 하나씩 냅니다.**

배운 내용의 앞선 설명은 질문을 만들 때 사용하지 않습니다. 목표가 여러 개이면 한 번에 하나만 묻고 예시나 힌트는 제공하지 않습니다.

### 5. 답변을 진단하고 기록합니다

**공통 학습 모델의 세 결과로 목표마다 진단합니다.**

진단 기준과 질문 이력의 최대 도움 단계·해결 근거만 사용합니다. 코드와 `TASK.md`를 확인해 답을 보충하지 않습니다.

복습 이력에는 예정일, 실행일, 질문, 목표별 진단, 병합 여부를 한 행으로 기록합니다. 재학습이 필요한 목표가 있으면 다음 날을 `next_supplemental_review_at`에 씁니다.

### 6. 다음 학습을 제안합니다

**결과가 가장 낮은 목표부터 다음 학습을 제안합니다.**

| 가장 낮은 결과 | 제안 |
| --- | --- |
| 재학습 필요 | 같은 목표를 다른 상황에서 다시 학습 |
| 부분 이해 | 같은 수준의 다른 학습 활동 |
| 모두 독립 설명 | 다음 수준의 새 주제 |

숙련 수준에서 모든 목표를 독립 설명했으면 수준은 유지하고 다른 주제를 제안합니다. 제안에는 다음 활동, 진단 근거, `init`에 전달할 문장을 포함합니다.

`manager`는 제안만 하고 예제 폴더나 기록의 새 예제 항목을 만들지 않습니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 예제 폴더 안에서 호출함 | 학습 공간에서 다시 호출하도록 안내 |
| `.study/records/`가 없음 | `init`으로 예제를 먼저 준비하도록 안내 |
| 완료되지 않은 기록만 있음 | `tutor`에서 완료 확인하도록 안내 |
| 기록을 읽을 수 없음 | 해당 파일 제외와 경로 안내 |
| 목표별 진단 기준이 없음 | 진단하지 않고 누락 필드 안내 |
| 완료 시각 형식이 잘못됨 | 해당 기록 제외와 필드 안내 |
| 복습 답변을 건너뜀 | 해당 목표를 재학습 필요로 기록 |
| 기록에 쓰지 못함 | 저장한 것처럼 알리지 않고 실패 경로 안내 |
| 14일 복습까지 끝남 | 대상에서 제외하고 복습 완료 안내 |
| 사용자가 제안을 원하지 않음 | 진단 결과만 알리고 종료 |

## 경계

| 사용자가 하려는 것 | 부르는 스킬 |
| --- | --- |
| 예제를 새로 받기 | `init` |
| 구현 중 질문·완료 확인 | `tutor` |
| 완료된 예제의 기록·복습 | `manager` |

- 배운 내용과 복습 답변을 대신 쓰지 않습니다.
- 예제 폴더를 만들거나 고치지 않습니다.
- 사용자가 호출하지 않았는데 복습 시점을 먼저 알리지 않습니다.
