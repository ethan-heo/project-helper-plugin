# manager

## 역할과 목적

`manager`는 마친 예제에서 배운 내용을 사용자에게 받아 적고, 시간이 지난 뒤 그 내용을 다시 꺼내 보게 한다. 꺼낸 결과로 무엇을 기억하고 무엇을 잊었는지 가리고, 다음에 할 학습을 제안한다.

사용자는 설명과 복습의 주체이고, AI는 대상 선정·질문·진단·기록을 맡는다.

## 실행 원칙

**배운 내용과 복습 답변은 사용자에게서 받고, 대신 채우지 않는다.**

## 부르는 위치

**학습 공간에서만 부른다.** 학습 공간은 예제 폴더들과 `.study/records/`가 함께 놓인 디렉터리다.

예제 폴더 안에서 부르면 진단하지 않고 학습 공간에서 부르라고 알린다. 기록 전체를 훑어야 복습 대상을 고를 수 있기 때문이다.

## 두 갈래 분기

**`.study/records/`의 기록을 읽어 무엇을 할지 가린다.**

| 기록 상태 | 하는 일 |
| --- | --- |
| `배운 내용` 절이 빈 기록이 있다 | 그 예제들을 목록으로 보이고 배운 내용을 받아 적는다 |
| 복습 시점이 지난 기록이 있다 | 밀린 예제와 시점을 보이고 복습을 진행한다 |
| 둘 다 있다 | 두 목록을 함께 보이고 사용자가 고른다 |
| 둘 다 없다 | 할 일이 없음을 알리고 다음 복습 시점을 알린다 |

## 읽는 것과 쓰는 것

| 대상 | 권한 |
| --- | --- |
| `.study/records/`의 기록 파일 | `배운 내용`과 `복습 이력` 절만 쓴다 |
| 기록의 `예제`·`질문 이력` 절 | 읽기만 한다 |
| 예제 폴더의 `TASK.md`·`PLAN.md`·코드 | 읽지 않는다 |

예제 폴더를 읽지 않는 이유는, 배운 내용을 사용자가 코드를 보지 않고 설명한 답으로 채우기 때문이다. `manager`가 코드를 읽으면 그 답을 대신 채우기 쉬워진다.

## 참조 문서 규칙

이 문서가 `manager`의 실행 지시사항을 정하는 기준 문서다.

| 문서 | 역할 | 읽는 시점 |
| --- | --- | --- |
| `SKILL.md` | 실행 절차와 판정 기준 | `manager` 전체 |
| `.study/records/`의 기록 파일 | 학습 목표, 답변 단계, 마친 날짜, 복습 이력 | 분기를 가릴 때와 진단할 때 |

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 예제 폴더 안에서 불렀다 | 진단하지 않고 학습 공간에서 부르라고 알린다 |
| `.study/records/`가 없다 | 진단하지 않고 `init`으로 예제를 먼저 만들라고 알린다 |
| 기록 파일을 읽을 수 없다 | 그 파일을 빼고 건너뛴 파일을 알린다 |

## 경계

**사용자가 하려는 일에 따라 부르는 스킬이 갈린다.**

| 사용자가 하려는 것 | 부르는 스킬 |
| --- | --- |
| 예제를 새로 받기 | `init` |
| 구현 중 모르는 것 묻기 | `tutor` |
| 마친 예제를 복습하고 진단받기 | `manager` |

- 배운 내용과 복습 답변을 대신 쓰지 않는다.
- 예제 폴더를 만들거나 고치지 않는다.
- 개념을 풀어 주는 강의는 이 스킬의 범위가 아니다.
