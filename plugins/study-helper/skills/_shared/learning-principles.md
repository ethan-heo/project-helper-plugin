# 학습 기조

## 목적

사용자가 정한 학습 원칙을 한곳에 모읍니다. 스킬은 과제·힌트·피드백을 만들 때 이 원칙을 판단 근거로 삼고, 적용 방법은 각 스킬 문서에 적습니다.

## 쓰는 방법

원칙마다 `P<번호>` 형식의 식별자가 붙습니다. 스킬 문서의 적용 규칙은 근거가 된 원칙을 이 식별자로 가리킵니다.

번호는 문서 전체에서 이어지며, 지운 번호는 다시 쓰지 않습니다. 원칙을 고치거나 더할 때는 그 원칙을 가리키는 적용 규칙도 함께 고칩니다.

## 기억 학습

| ID | 원칙 |
| --- | --- |
| P1 | 학습에는 반드시 노력이 든다 |
| P2 | 머릿속에서 꺼내는 데 노력을 많이 들일수록 얻는 것이 크다 |
| P3 | 꺼내 보면 무엇을 알고 무엇을 모르는지 드러난다 |
| P4 | 배운 것을 회상하면 연관이 강해져 다음에 떠올리기 쉬워진다 |
| P5 | 시험은 꺼내 보게 만드는 수단이다 |
| P6 | 시간 간격을 둔 반복이 기억을 오래 남긴다 |
| P7 | 자신의 말로 바꿔 기존 지식과 연결하면 기억이 자리를 덜 차지한다 |
| P8 | 넓은 맥락에서 보면 연관된 내용이 늘어 의미와 기억이 여러 갈래로 생긴다 |

## 학습 습관

| ID | 원칙 |
| --- | --- |
| P9 | 해법을 보기 전에 스스로 풀려고 애쓰면 더 잘 배운다 |
| P10 | 사전 지식이 있으면 올바른 해결책을 찾을 확률이 높다 |
| P11 | 사전 지식은 새로운 것을 익히는 재료로 쓰인다 |
| P12 | 여러 실습을 번갈아 하면 다양한 상황에서 쓸 수 있게 된다 |
| P13 | 내용에 익숙해진 것과 소화한 것은 다르다 |
| P14 | 익숙함을 이해로 착각하는 것은 무엇을 아는지 모르는 상태다 |
| P15 | 추상적인 지식이 구체적이고 개인적인 것으로 바뀌는 순간 학습이 일어난다 |

## 기억할 것

| ID | 원칙 |
| --- | --- |
| P16 | 반복만으로는 실력이 늘지 않으며 전략이 필요하다 |
| P17 | 힘들면 쉬운 방법을 택하게 되고, 그러면 같은 것을 다시 반복하게 된다 |
| P18 | 거듭 실패하며 익힌 지식은 다른 전략이 필요하다는 신호다 |
| P19 | 배울 때 받은 조언을 무턱대고 믿지 않는다 |
