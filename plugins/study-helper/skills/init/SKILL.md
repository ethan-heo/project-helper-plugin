# init

## 역할과 목적

`init`은 배우고 싶은 기술 하나를 받아, 사용자가 직접 구현할 예제를 낸다. 예제를 만들기 전에 `tutor` 문서의 절차로 학습자 수준과 학습 목표를 정하고, 그 수준에 맞는 형태로 예제와 환경을 준비한다.

사용자는 무엇을 배울지 정하는 결정권자이고, AI는 질문·예제 선정·환경 준비를 맡는다.

## 실행 원칙

**수준을 받기 전에 예제를 만들지 않고, 그 수준이 정한 범위를 넘겨 만들어 주지 않는다.**

## 읽는 것과 쓰는 것

| 대상 | 권한 |
| --- | --- |
| 사용자가 건넨 경로·링크·코드 조각·글 | 읽기만 한다 |
| `tutor/SKILL.md`의 `예제 구성 방향` 절 | 읽기만 한다 |
| 현재 디렉터리의 예제 폴더들의 `TASK.md` | 읽기만 한다 |
| 새 예제 폴더의 `README.md`·`TASK.md`·`PLAN.md` | 만들고 쓴다 |
| `.study/records/` 아래 그 예제의 기록 파일 | 만들고 `예제` 절만 쓴다 |

`PLAN.md`는 빈 양식으로 만들고 내용을 채우지 않는다. 사용자가 쓰는 문서이기 때문이다.

예제 폴더에 예제를 완성하는 코드를 만들지 않는다. 다만 입문 수준에서는 실행되는 예제를 주고 동작을 설명한다. 어느 수준에서 무엇을 주는지는 `tutor` 문서의 `예제 구성 방향` 절이 정한다.

## 참조 문서 규칙

이 문서가 `init`의 실행 지시사항을 정하는 기준 문서다.

| 문서 | 역할 | 읽는 시점 |
| --- | --- | --- |
| `SKILL.md` | 실행 절차와 판정 기준 | `init` 전체 |
| `../tutor/SKILL.md`의 `예제 구성 방향` 절 | 수준·학습 목표·예제 범위 결정 절차 | 예제를 만들기 전 |
| `assets/readme-template.md` | 예제 폴더 `README.md` 양식 | 예제를 기록할 때 |
| `assets/task-template.md` | `TASK.md` 양식 | 예제를 기록할 때 |
| `assets/plan-template.md` | `PLAN.md` 양식 | 예제를 기록할 때 |
| `assets/record-template.md` | 기록 파일 양식 | 예제를 기록할 때 |

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 기술 이름도 자료도 없이 불렀다 | 무엇을 공부할지 묻고 기다린다 |
| `tutor/SKILL.md`를 읽을 수 없다 | 예제를 만들지 않고 읽지 못한 경로를 알린다 |
| 사용자가 예제 코드를 대신 써 달라고 한다 | 수준이 정한 범위를 넘겨 쓰지 않는다 |

## 경계

**사용자가 하려는 일에 따라 부르는 스킬이 갈린다.**

| 사용자가 하려는 것 | 부르는 스킬 |
| --- | --- |
| 예제를 새로 받기 | `init` |
| 구현 중 모르는 것 묻기 | `tutor` |
| 마친 예제를 복습하고 진단받기 | `manager` |

수준 판정과 학습 목표 결정은 `tutor` 문서의 절차를 읽어 이 스킬의 대화에서 수행한다. 사용자가 `tutor`를 따로 부르지 않는다.

- 예제를 완성하는 코드와 정답은 제시하지 않는다.
- 개념을 풀어 주는 강의는 이 스킬의 범위가 아니다.
