## 시작 순서

<!-- 이 절의 내용은 고치지 않는다. -->

1. `TASK.md`를 읽고 만들 대상과 완성 조건을 확인한다.
2. `PLAN.md`에 설계와 구현 단계를 먼저 적는다.
3. 코드를 쓰고, 완성 조건을 하나씩 확인한다.
4. 막히면 `PLAN.md`의 `막힌 점`에 무엇을 시도했고 무엇이 안 되는지 적는다.
5. 그래도 풀리지 않으면 이 폴더에서 `tutor`를 부른다. 처음에는 무엇을 시도했는지 되묻고, 더 알려 달라고 할 때만 한 단계씩 넓혀 답한다.
