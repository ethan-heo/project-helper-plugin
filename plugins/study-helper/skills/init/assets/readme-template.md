## 시작 순서

<!-- 이 절의 내용은 고치지 않는다. -->

1. `TASK.md`를 읽고 학습 활동, 배경, 학습 목표, 진행 방향, 완성 조건을 확인한다.
2. `PLAN.md`에 설계와 구현 단계를 먼저 적는다.
3. 활동을 진행하고, 완성 조건을 하나씩 확인한다. 산출물이 원인이나 관찰 결과이면 `PLAN.md`의 `기록` 절에 적는다.
4. 막히면 `PLAN.md`의 `막힌 점`에 무엇을 시도했고 무엇이 안 되는지 적는다.
5. 그래도 풀리지 않으면 이 폴더에서 `tutor`를 부른다. `막힌 점`에 시도와 막힌 지점이 모두 있으면 다음 확인 지점부터 답한다.
6. 완성 조건을 모두 확인한 뒤 `tutor`에게 완료 확인을 요청한다. `tutor`가 결과를 확인해야 복습 대상으로 기록된다.
