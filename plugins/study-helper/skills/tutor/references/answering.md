# 질문별 도움 단계

## 목적

사용자가 이미 제공한 시도를 다시 묻지 않고 요청한 범위까지만 도움을 줍니다.

## 단계

| 단계 | 답변 범위 |
| --- | --- |
| 1 | `tutor`를 부르기 전 사용자의 독립 시도 |
| 2 | 시도 내용이나 막힌 지점 중 빠진 정보 질문 |
| 3 | 관련 개념과 다음에 확인할 지점 제시 |
| 4 | 필요한 코드나 접근 방법의 일부 설명 |
| 5 | 해결에 필요한 최소 코드 조각과 적용 위치 설명 |

5단계에서도 학습자의 파일을 수정하지 않습니다. 질문과 관계없는 완성 코드나 다음 기능을 제시하지 않습니다.

## 시작 단계

**새 주제는 현재 메시지와 `PLAN.md`에 있는 시도 정보를 먼저 확인합니다.**

| 확인 결과 | 시작 단계 |
| --- | --- |
| 시도 내용과 막힌 지점이 모두 있음 | 3단계 |
| 둘 중 하나라도 없음 | 2단계 |

2단계에서는 빠진 정보만 묻습니다. 사용자가 이미 말한 시도, 오류, 관찰 결과는 다시 요청하지 않습니다.

## 주제 판정

질문의 대상과 해결하려는 문제가 같으면 같은 주제입니다. 대상이나 해결 목표가 다르면 새 주제입니다.

같은 주제인지 판단할 근거가 부족하면 기존 주제와 새 주제 중 어느 쪽인지 한 번만 묻습니다. 답을 받기 전에는 기존 단계나 새 단계로 추정하지 않습니다.

## 단계 변경

**도움을 더 직접적으로 달라는 명시적 요청에서만 한 단계 높입니다.**

| 요청 | 단계 변화 |
| --- | --- |
| 다음 힌트·더 직접적인 방법 | 한 단계 상승 |
| 다른 표현의 재설명 | 같은 단계 유지 |
| 같은 범위의 예시 | 같은 단계 유지 |
| 결과 확인 | 같은 단계 유지 |
| 5단계 이후 추가 도움 | 5단계 유지 |

한 응답에서 두 단계 이상 올리지 않습니다. 단계가 유지될 때는 내용의 범위를 넓히지 않고 표현이나 예시만 바꿉니다.

## 기록

**질문 이력은 주제별로 한 행을 유지합니다.**

새 주제에는 다음 주제 ID를 부여하고 연결된 목표, 이번 단계, `해결 여부: 아니요`, 빈 확인 근거를 기록합니다. 같은 주제에서는 최대 도움 단계가 커질 때만 값을 바꿉니다.

## 예외 처리

| 예외 조건 | 할 일 |
| --- | --- |
| 질문만 있고 시도 정보가 없음 | 2단계에서 시도 내용 질문 |
| 시도만 있고 막힌 지점이 없음 | 2단계에서 막힌 지점 질문 |
| 주제 연속 여부가 모호함 | 한 번 확인하고 답을 기다림 |
| 5단계에서 파일 수정을 요청함 | 최소 코드 조각만 제시하고 수정 거절 |
